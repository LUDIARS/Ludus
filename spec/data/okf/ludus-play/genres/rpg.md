# コア体験

RPGは、キャラクター成長と戦略的戦闘、物語進行を統合したジャンル。数値管理、進行システム、選択と結果が長期的な体験を形成する。

# 実装順序

1. 基本戦闘システム: ターン制またはリアルタイム
2. レベル/経験値: 成長の基礎
3. ステータス管理: 能力値の計算
4. インベントリ: アイテム管理の基盤
5. 装備システム: 外部成長の実装
6. スキルシステム: 戦術の多様化
7. クエストシステム: 目標と報酬の提示
8. パーティシステム: 複数キャラ管理(オプション)
