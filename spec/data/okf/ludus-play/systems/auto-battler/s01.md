# 目的

戦闘前の戦略的配置を提供し、勝敗を事前準備で決める。

# 設計思想

配置システムは「チェスの初期配置」に似た戦略性を持つ。前列にタンク、後列にアタッカーという基本から、シナジーを考えた複雑な配置まで、深みがある。戦闘は自動だが、事前の配置が全てを決める。

# 主要機能

- グリッド配置: 3x3や4x4のマス目
- 前衛/後衛: ポジションによる役割
- 配置制限: 出撃可能なユニット数
- シナジー: 種族やクラスの組み合わせ
- 配置保存: 複数パターンの記録
- ドラッグ配置: 直感的な操作
