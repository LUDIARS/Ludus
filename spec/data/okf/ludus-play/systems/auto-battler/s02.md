# 目的

プレイヤー操作不要の戦闘を提供し、観戦の楽しさを作る。

# 設計思想

自動戦闘は「忙しい人向けの設計」である。アクションゲームのような反射神経不要で、通勤中や休憩中にサクッと遊べる。倍速やスキップで時間短縮し、リプレイで「なぜ負けたか」を分析できる。

# 主要機能

- AI行動: ユニット自身の判断で行動
- ターゲット選択: 最も近い敵、最も弱い敵など
- スキル発動: 自動での特殊能力使用
- 戦闘速度: 等速、倍速、スキップ
- 戦闘ログ: 行動履歴の記録
- リプレイ: 戦闘の再生
