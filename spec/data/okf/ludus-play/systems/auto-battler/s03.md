# 目的

ランダムな選択肢からユニットを獲得させ、運と判断のバランスを作る。

# 設計思想

ドラフトシステムは「運と実力のバランス」を作る。完全ランダムだと理不尽で、固定だと戦略性がない。リロール機能で「運が悪くても通貨で改善できる」選択肢を提供し、実力の介入余地を残す。

# 主要機能

- ランダム提示: 3-5体のユニット選択肢
- ピック: 1体を選んで獲得
- リロール: 通貨消費で選択肢更新
- レベルアップ: プレイヤーレベルで選択肢増加
- レアリティ: 上位ユニットの出現率
- 固定枠: 必ず出現するユニット
