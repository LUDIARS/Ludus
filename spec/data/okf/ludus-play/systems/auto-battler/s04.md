# 目的

ユニット間の組み合わせボーナスを提供し、編成の方向性を作る。

# 設計思想

シナジーシステムは「全体最適化の追求」を要求する。最強ユニット5体より、シナジーが発動する編成の方が強い場合がある。ドラフトの運に左右されつつも、「手札で最善を尽くす」戦略性が生まれる。

# 主要機能

- 種族シナジー: エルフ、ドワーフ、アンデッドなど
- クラスシナジー: 戦士、魔法使い、暗殺者など
- 発動条件: 3体、6体、9体で段階的強化
- 効果: ステータス上昇、特殊能力付与
- 複合シナジー: 複数のトレイト同時発動
- 視覚的表示: 発動中のシナジー明示
