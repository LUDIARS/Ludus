# 目的

段階的な難易度上昇を提供し、勝ち残りの緊張感を作る。

# 設計思想

ラウンド進行は「バトルロイヤルの構造」を持つ。最初は全員生存、徐々に脱落者が出て、最後の1人が勝者。長期戦(30分程度)で、序盤の不運も中盤以降の立て直しで挽回できる設計。

# 主要機能

- ラウンド数: 通常30-40ラウンド
- 敵の強化: ラウンドごとに敵が強くなる
- PvE/PvP交互: モンスターと他プレイヤー
- ライフ: 敗北ごとに減少
- ゲームオーバー: ライフ0で脱落
- 順位: 最後まで残った順位
