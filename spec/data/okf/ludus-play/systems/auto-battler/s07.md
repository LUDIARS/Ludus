# 目的

ユニットのカスタマイズを提供し、同じユニットでも差別化を可能にする。

# 設計思想

アイテムシステムは「ランダム要素の追加的調整」を担う。ドラフトでユニットが揃わなくても、良いアイテムが出れば補える。合成システムで「同じアイテム3個」という条件が、運と戦略のバランスを作る。

# 主要機能

- アイテムドロップ: ラウンド報酬やモンスター撃破
- 装備: ユニットへのアイテム付与
- 合成: 同じアイテム3個で上位化
- 効果: ステータス向上、特殊能力
- 装備枠: ユニットごとに1-3個
- 完成アイテム: 複数素材の組み合わせ
