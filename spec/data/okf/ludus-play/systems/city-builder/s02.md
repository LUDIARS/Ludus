# 目的

時間経過による資源生成を提供し、定期的なログインを促す。

# 設計思想

生産システムは「時間を資源に変換」する。短時間生産(5分)は頻繁なログイン、長時間生産(8時間)は就寝中や外出中に適する。プレイヤーのライフスタイルに合わせた選択肢を提供する。

# 主要機能

- 生産施設: 農場、工場、店舗など
- 生産時間: 数分〜数時間の待機
- 収穫: タップで資源回収
- 生産上限: 一定量で停止
- 自動収穫: 課金やアップグレードで自動化
- 複数資源: 小麦、木材、コイン、経験値など
