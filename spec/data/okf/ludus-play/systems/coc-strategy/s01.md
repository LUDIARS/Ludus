# 目的

防衛拠点を構築し、攻撃から資源を守る砦を作る。

# 設計思想

基地建設は「タワーディフェンスの自作」である。攻撃側の動線を予測し、防衛施設を最適配置する。壁で敵を誘導し、集中砲火できるチョークポイントを作る戦略性が深みを生む。

# 主要機能

- 建物配置: タウンホール、資源施設、防衛施設
- グリッド配置: マス目または自由配置
- 壁の建設: 敵の進路制御
- 配置の保存: 複数レイアウトの切り替え
- 建設時間: 完成までの待機
- ビルダー数: 同時建設可能数
