# 目的

攻撃用の軍隊を編成し、戦術的な部隊構成を考えさせる。

# 設計思想

ユニット編成は「攻撃の手札」を作る。地上ユニットは安いが対空砲に弱い、空中は高いが防衛施設を避けられるなど、一長一短の設計。キャンプ容量制限で、全種類は持てない選択を強いる。

# 主要機能

- ユニット種類: 地上、空中、特殊
- 訓練時間: ユニットごとの生成時間
- 訓練コスト: エリクサー消費
- キャンプ容量: 出撃可能な総数
- 編成の保存: 複数の軍隊テンプレート
- クイック訓練: ワンタップで全補充
