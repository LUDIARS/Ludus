# 目的

プレイヤー集団を形成し、社会的つながりと協力目標を提供する。

# 設計思想

クランシステムは「社会的な継続動機」を作る。一人だと孤独で離脱しやすいが、クランメンバーがいると「迷惑をかけられない」という社会的圧力が生まれる。寄付で貢献度が可視化され、メンバー内での評価が生まれる。

# 主要機能

- クラン加入: 最大50人程度の団体
- チャット: メンバー間の会話
- 援軍要請: 防衛ユニットの提供
- 寄付システム: メンバーへのユニット提供
- クランレベル: 集団の成長
- クラン特典: レベルに応じたボーナス
