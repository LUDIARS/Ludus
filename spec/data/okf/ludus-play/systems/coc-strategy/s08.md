# 目的

定期的な変化を提供し、長期プレイヤーの飽きを防ぐ。

# 設計思想

シーズンシステムは「月単位の区切り」を作る。基地育成は年単位だが、シーズンは1ヶ月で完結する短期目標。シーズンパスは定額課金モデルで、安定収益を確保しつつプレイヤーに継続的な報酬を提供する。

# 主要機能

- シーズンパス: 月額制の追加報酬
- 期間限定イベント: 特別チャレンジ
- シーズンバンク: 資源の保護貯蔵
- 限定スキン: 見た目のカスタマイズ
- ランキングイベント: 上位者への報酬
- 特別セール: 期間限定の課金パック
