# 目的

30-40枚のカードを選択させ、戦略的な組み合わせを考えさせる。

# 設計思想

デッキ構築は「制約下の最適化」である。全カード入れられないため、何を採用し何を切るかの判断。マナカーブ(低コスト10枚、中コスト15枚、高コスト5枚など)で、バランスの取れた構成を促す。

# 主要機能

- デッキ枚数: 通常30枚前後
- 枚数制限: 同名カード2枚まで(レジェンダリーは1枚)
- クラス/ヒーロー: デッキの軸となる職業
- マナカーブ: コストバランスの最適化
- シナジー: カード間の相乗効果
- アーキタイプ: アグロ、コントロール、コンボなど
