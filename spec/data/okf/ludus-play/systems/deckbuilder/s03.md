# 目的

戦略的な思考時間を提供し、リソース管理を要求する。

# 設計思想

マナシステムは「段階的な強化」を作る。序盤は弱いカード、終盤は強力なカードという自然な流れ。毎ターン全回復で計算が簡単になり、使い切りを前提とした戦略が立てやすい。

# 主要機能

- 交互ターン: プレイヤーが順番に行動
- マナ: カードプレイのコスト
- マナ増加: ターンごとに上限+1
- マナ回復: 毎ターン全回復
- ドロー: ターン開始時に1枚
- ターン制限時間: 60-90秒程度
