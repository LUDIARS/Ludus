# 目的

プレイスタイルの方向性を定義し、デッキの個性を作る。

# 設計思想

クラスシステムは「プレイスタイルの分類」を担う。全員が同じカードプールだと個性がなく、完全に別ゲームだと複雑すぎる。専用カードと中立カードの比率(専用30%、中立70%など)で差別化とバランスを取る。

# 主要機能

- クラス専用カード: 特定クラスのみ使用可能
- 中立カード: 全クラスで使用可能
- ヒーローパワー: 2マナの固有能力
- クラス特性: メイジは呪文、ウォリアーは武器など
- 複数ヒーロー: 同クラスでも異なる選択肢
- シナジーの方向性: クラス内での統一感
