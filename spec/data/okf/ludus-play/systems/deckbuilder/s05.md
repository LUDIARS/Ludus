# 目的

カードの効果を実際の戦闘に反映し、戦術的な駆け引きを作る。

# 設計思想

バトルシステムは「盤面の支配権争い」を作る。ミニオンで盤面を取るか、スペルで除去するか、顔面を攻めるか。挑発は防御的、疾走は攻撃的という役割分担で、戦略の幅を広げる。

# 主要機能

- ミニオン召喚: 場に残る攻撃ユニット
- スペル: 即座に発動する呪文
- 攻撃と防御: 相互ダメージ交換
- 挑発: 優先攻撃対象の強制
- 疾走: 召喚ターンから攻撃可能
- HP管理: ヒーロー30、ミニオン個別
