# 目的

競争の場を提供し、上達の可視化と報酬を設定する。

# 設計思想

ランクシステムは「継続的な挑戦」を提供する。シーズンリセットで毎月新鮮な挑戦が始まり、連勝ボーナスで爆発的な上昇も可能。保護ラインで、一度到達したランクから大きく落ちない安心感を与える。

# 主要機能

- ランク階層: ブロンズ、シルバー、ゴールド、レジェンド
- 星システム: 勝利で星獲得、敗北で星喪失
- 連勝ボーナス: 連続勝利で星2倍
- ランク保護: 一定以下には落ちない
- シーズンリセット: 月初にランク下降
- 報酬配布: ランクに応じたカードパック
