# 目的

コレクション依存でない競技場を提供し、純粋な構築力を試す。

# 設計思想

アリーナは「技術の試金石」である。課金でカードを揃えた人も、無課金でも、アリーナでは対等。ドラフトの選択センスと、組んだデッキでの勝率が純粋に試される。入場料制で、真剣勝負の緊張感を生む。

# 主要機能

- ドラフトピック: ランダム3枚から1枚選択
- 30回選択: 30枚デッキの完成
- 入場料: ゴールドまたは課金通貨
- 勝利報酬: 勝ち数に応じた報酬増加
- 3敗で終了: 最大12勝まで
- 報酬の累進: 高勝利ほど豪華な報酬
