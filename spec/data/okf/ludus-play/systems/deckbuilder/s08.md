# 目的

毎日のログイン習慣を作り、継続的な報酬で無課金者を支援する。

# 設計思想

デイリークエストは「無課金経済の柱」である。課金者は時間を買い、無課金者は時間をかけて同等のカードを集められる。クエストで1日50-60ゴールド、パック1個が100ゴールドなら、2日で1パック開けられる計算。

# 主要機能

- デイリークエスト: 3つの日替わり任務
- クエスト内容: 特定クラスで勝利、カードプレイなど
- 報酬: ゴールド、カードパック、素材
- 再抽選: 1日1回のクエスト変更
- ウィークリー報酬: 週単位の大型報酬
- 初回勝利: 毎日最初の勝利でボーナス
