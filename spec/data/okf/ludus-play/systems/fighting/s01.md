# 目的

複雑なボタン/レバー操作を認識し、多様な技を実行可能にする。

# 設計思想

コマンド入力は「格闘ゲームの言語」である。複雑すぎると初心者が技を出せず、単純すぎると奥深さがない。基本技は簡単(単ボタン)、必殺技は中程度(236+P)、超必殺技は難しい(236236+PP)という段階設計が一般的。

# 主要機能

- 方向入力: レバーの8方向(上下左右+斜め4方向)
- コマンド認識: 波動拳コマンド(↓↘→+P)などの検出
- 入力バッファ: 数フレームの先行入力を受付
- 同時押し判定: 複数ボタンの同時入力
- コマンド優先度: 複数マッチ時の優先順位
- 簡易入力: 初心者向けの短縮コマンド
