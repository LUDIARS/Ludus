# 目的

すべての行動に発生/持続/硬直フレームを設定し、攻防の駆け引きを作る。

# 設計思想

フレームデータは「時間の戦略化」である。すべての行動に時間コストがあり、有利フレームが次の行動の優先権を決める。1フレーム=1/60秒の精度で、数フレームの差が勝敗を分ける。

# 主要機能

- 発生フレーム: 技が出るまでの時間
- 持続フレーム: 攻撃判定が出ている時間
- 硬直フレーム: 技後の動けない時間
- ガード硬直: ガード時の相手の硬直
- フレーム有利/不利: 技後の攻防の先手後手
- キャンセル: 硬直を別の技で上書き
