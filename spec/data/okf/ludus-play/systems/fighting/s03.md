# 目的

攻撃と防御の当たり判定を管理し、公平で明確なヒット検出を実現する。

# 設計思想

ヒットボックスは「空間の戦略化」である。見た目と判定が一致することが公平性の基本。リーチが長い技は発生が遅い、無敵技は隙が大きいなど、判定の強さと他の要素でバランスを取る。

# 主要機能

- 攻撃判定(ヒットボックス): 攻撃が当たる領域
- 喰らい判定(ハートボックス): ダメージを受ける領域
- 投げ判定: 掴み技の特殊な判定
- 無敵判定: 特定フレームで喰らい判定が消える
- ガード判定: 防御状態の判定
- 優先度: 同時ヒット時の処理
