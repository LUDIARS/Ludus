# 目的

攻撃を防ぐ手段を提供し、攻守の駆け引きを成立させる。

# 設計思想

ガードシステムは「防御の複雑化」を担う。完全防御が可能だと膠着状態になり、ガード不能だと攻め一辺倒になる。上中下の択、投げ、ガードクラッシュで「守りきれない状況」を作る。

# 主要機能

- 立ちガード: 上段・中段攻撃を防ぐ
- しゃがみガード: 中段・下段攻撃を防ぐ
- 空中ガード: ジャンプ中の防御(ゲームによる)
- ガードクラッシュ: 過度な防御で崩される
- 削りダメージ: ガード中もわずかにダメージ
- ジャストガード: タイミング良いガードで有利
