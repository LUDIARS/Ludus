# 目的

通常技を超える強力な技を提供し、戦略の幅と逆転の可能性を生む。

# 設計思想

必殺技システムは「資源管理の戦略化」である。ゲージは攻撃で溜まるため攻める側が有利だが、超必殺技は切り返しにも使える。EX版(ゲージ消費で強化)、ガードキャンセル、超必殺技など、複数の用途で戦略性を生む。

# 主要機能

- 必殺技: コマンド入力で発動する特殊技
- 超必殺技: ゲージ消費の強力技
- ゲージ管理: 攻撃やダメージで蓄積
- 無敵時間: 発動時に攻撃を受けない
- 演出: 暗転やカットインでの強調
- ゲージ使用の選択: 超必殺技か他の用途か
