# 目的

ガード一辺倒を崩す手段を提供し、近距離での読み合いを作る。

# 設計思想

投げシステムは「ジャンケンの構造化」である。打撃はガードに負けて投げに勝ち、ガードは打撃に勝って投げに負ける。投げ抜けの猶予フレームで、反応速度と読みのバランスを調整する。

# 主要機能

- 投げコマンド: 近距離で特定入力
- 投げ無敵: しゃがみや特定技で回避
- 投げ抜け: 相手の投げに合わせて入力
- 投げ抜け猶予: タイミング判定の寛容さ
- 空中投げ: 空中での掴み技
- コマンド投げ: 抜けられない強力な投げ
