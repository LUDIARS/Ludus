# 目的

前後移動による距離の制御を通じて、攻防の優位性を作る。

# 設計思想

間合い管理は「空間の支配権争い」である。全キャラが同じリーチだと単調で、差が大きすぎると不公平。リーチが長いキャラは機動力が低い、近距離キャラは火力が高いなど、距離特性で差別化する。

# 主要機能

- 歩き: 低速だが柔軟な移動
- ダッシュ: 高速だが硬直がある移動
- バックステップ: 後退しながら無敵
- 技のリーチ: 各技の攻撃距離
- ステップキャンセル: 移動を技で中断
- 前後の駆け引き: ギリギリで技を避ける
