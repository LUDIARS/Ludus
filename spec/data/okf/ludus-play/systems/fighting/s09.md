# 目的

垂直方向の移動と攻撃を提供し、立体的な攻防を作る。

# 設計思想

ジャンプシステムは「高さの戦略化」である。飛びが強すぎると地上戦が成立せず、弱すぎると選択肢が減る。対空技の存在で「飛びは読まれるとリスク」というバランスを作る。

# 主要機能

- 垂直ジャンプ: その場で上昇
- 前後ジャンプ: 放物線を描いて移動
- 空中攻撃: ジャンプ中の技
- めくり: 相手の反対側に着地する攻撃
- 対空技: 飛びを落とす地上技
- 空中ダッシュ: 空中での高速移動
