# 目的

攻撃が当たったか見てから次の行動を選択する技術を可能にする。

# 設計思想

ヒット確認は「観察力のゲーム化」である。人間の反応速度(15-20フレーム)を考慮し、確認可能な技と不可能な技を設計する。確認可能な技は他の面で弱く、不可能な技は強いがリスキーというバランス。

# 主要機能

- ヒットストップ: 命中時の一時停止で確認時間
- キャンセル猶予: ヒット確認後のコンボ移行
- ガード時の変化: ヒットとガードで音・演出が異なる
- 2段技: 1段目で確認、2段目でキャンセル
- 目押し: フレーム単位のタイミング入力
