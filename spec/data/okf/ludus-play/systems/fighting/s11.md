# 目的

ステージの端を戦略的要素として活用し、追い詰める価値を生む。

# 設計思想

画面端は「空間の非対称性」を作る。中央では両方向に逃げられるが、端では片方しか選択肢がない。この不利を覆す強力な端脱出技(無敵技)と、追い詰める価値(高ダメージ)のバランスが戦略を生む。

# 主要機能

- 画面端判定: ステージの境界
- 壁バウンド: 端で跳ね返りコンボ延長
- 追い詰める価値: 端では逃げ場がない
- 端脱出技: リバーサルやガードキャンセル
- 端限定コンボ: 通常より高ダメージ
- 位置入れ替え: 端を背負う不利を逆転
