# 目的

不利な状況からの脱出手段を提供し、一方的な攻めを防ぐ。

# 設計思想

リバーサルシステムは「攻守の均衡化」である。攻め側が完全有利だと一方的になり、切り返しが強すぎると攻めるリスクが高すぎる。ゲージ消費や大きな隙で、使用タイミングを慎重にさせる。

# 主要機能

- リバーサル判定: 起き上がり直後の技
- 無敵技: 発生から無敵の切り返し技
- ガードキャンセル: ガード中から技発動
- 割り込み: 連携の隙間に技を差し込む
- リバーサルタイミング: 1-2フレームの猶予
- リスクとリターン: 失敗すると大きな隙
