# 目的

キャラクターやアイテムのランダム取得を提供し、収集欲と期待感を刺激する。

# 設計思想

ガチャシステムは「期待の商品化」である。完全ランダムだと不公平感が強く、確定だと期待感がない。天井システムで最悪ケースを保証しつつ、低確率の興奮を残す。排出率の明示は透明性と信頼の確保。

# 主要機能

- ガチャ種類: 通常、プレミアム、期間限定、ステップアップ
- レアリティ階層: N、R、SR、SSR、URなど
- 排出率: レアリティごとの確率表示
- 天井システム: 一定回数で確定入手
- ピックアップ: 特定キャラの排出率上昇
- 演出: レア確定の予告演出
