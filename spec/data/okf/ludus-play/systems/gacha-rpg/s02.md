# 目的

段階的な成長を提供し、長期的な投資と愛着を生む。

# 設計思想

育成システムは「時間投資の可視化」である。即座に最強にできると愛着が湧かず、遅すぎるとストレス。複数の育成軸(レベル、覚醒、スキル、装備)で、常に「次にやること」を提供する。

# 主要機能

- レベル上げ: 経験値アイテムまたは戦闘で成長
- 限界突破: 同キャラ合成でレベル上限解放
- 覚醒/進化: 素材消費で上位レアリティ化
- スキルレベル: 技の威力や効果向上
- 装備強化: 武器や防具のレベルアップ
- 親愛度/絆: プレイヤーとの関係値
