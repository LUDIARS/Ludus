# 目的

プレイ時間を制限し、適度な休憩と長期的な継続を促す。

# 設計思想

スタミナシステムは「プレイペースの調整」を担う。無制限だと燃え尽きやすく、厳しすぎると不満が溜まる。自然回復速度と消費量のバランスで、1日数回のログインを促す設計が一般的。

# 主要機能

- スタミナ消費: クエスト挑戦にコスト
- 自然回復: 時間経過で回復(3分で1など)
- 回復アイテム: 即座の全回復
- ランクアップ回復: レベルアップで全回復
- 上限値: 所持できる最大スタミナ
- 溢れ防止: 上限超過の受取ボックス
