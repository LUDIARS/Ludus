# 目的

毎日のログイン習慣を形成し、継続的なエンゲージメントを維持する。

# 設計思想

デイリーシステムは「習慨形成の仕組み」である。報酬が魅力的すぎると義務感が強くなり、少なすぎると無視される。適度な報酬と簡単なタスクで、「ついでに」達成できる設計が理想。

# 主要機能

- デイリー任務: 毎日リセットされる目標
- ログインボーナス: 起動するだけで報酬
- 連続ログイン: 日数に応じて豪華化
- ウィークリー任務: 週単位の長期目標
- 報酬の段階化: 初日は普通、7日目は豪華
- 取り逃し救済: 多少のログイン漏れを許容
