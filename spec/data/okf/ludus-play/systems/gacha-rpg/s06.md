# 目的

定期的な新鮮さを提供し、中だるみを防ぐ。

# 設計思想

イベントシステムは「季節感と変化」を作る。常設コンテンツのみだと飽きが来るため、2週間単位などで新イベントを投入。限定要素は希少価値を生むが、復刻で取り逃しの救済も必要。

# 主要機能

- 期間限定クエスト: 特定期間のみ挑戦可能
- イベント専用報酬: 限定キャラや装備
- ポイント累積: 周回で貯まるイベントpt
- 報酬ラダー: ポイントに応じた段階報酬
- ランキング: 上位者への追加報酬
- 復刻イベント: 過去イベントの再開催
