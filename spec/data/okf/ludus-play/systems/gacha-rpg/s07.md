# 目的

社会的つながりを作り、コミュニティによる定着率向上を図る。

# 設計思想

ギルドシステムは「社会的な継続動機」を提供する。ソロプレイのみだと孤独で離脱しやすいが、仲間がいると「みんなのために」という動機が生まれる。ただし、義務感が強すぎるとストレスになるバランス調整が必要。

# 主要機能

- ギルド加入: プレイヤー団体への所属
- ギルドバトル: 団体間の協力戦
- 寄付システム: メンバーへの支援
- チャット機能: コミュニケーション
- 協力レイド: 共同で強敵に挑戦
- ギルド特典: 所属によるボーナス
