# 目的

プレイヤー間の競争を提供し、編成の最適化と腕前の証明の場を作る。

# 設計思想

PvPシステムは「競争の場」を提供する。協力型のみだと比較対象がなく、PvPがあることで「誰が強いか」が明確になる。課金格差が大きすぎると不公平感が強いため、マッチングやシーズンリセットで公平性を保つ。

# 主要機能

- アリーナ/対戦場: 非同期のバトル
- 防衛編成: 自分不在時の自動戦闘
- ランキング: 順位による報酬
- シーズン制: 定期リセットと再挑戦
- マッチング: 近い戦力との対戦
- 報酬の段階化: 順位帯ごとの配布
