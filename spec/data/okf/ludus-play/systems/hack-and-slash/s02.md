# 目的

敵撃破による報酬を提供し、収集と成長のループを作る。

# 設計思想

ルートシステムは「ギャンブル的報酬」を提供する。確定報酬だと予測可能で面白みがなく、完全ランダムだと不公平。ドロップ率の調整(雑魚は低確率、ボスは高確率)で、努力が報われる感覚を作る。

# 主要機能

- ランダムドロップ: 確率で装備やアイテム獲得
- レアリティ階層: コモン、レア、エピック、レジェンダリー
- ドロップ率: 敵や難易度による確率変動
- 自動収集: 一定範囲内の自動取得
- 視覚的表現: レアリティで色分け(白、青、紫、金など)
- ルートフィルタ: 不要アイテムの非表示
