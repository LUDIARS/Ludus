# 目的

同じ装備でも異なる性能を持たせ、最適解の探索を促す。

# 設計思想

ランダム装備は「同じ剣でも別物」という多様性を生む。固定ステータスだと最適解が明確で探索の余地がない。ランダム幅(攻撃力100-150など)と、稀少な完璧ロール(150)の追求が、エンドコンテンツを支える。

# 主要機能

- ベースアイテム: 武器や防具の基本形
- ランダムステータス: 攻撃力、防御力の幅
- アフィックス: 追加効果(炎ダメージ、ライフ吸収など)
- 接頭辞/接尾辞: 複数の修飾語
- ソケット: 宝石を嵌める穴
- セットアイテム: 複数装備でボーナス
