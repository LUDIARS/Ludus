# 目的

キャラクターの成長方向を選択させ、プレイスタイルの個性化を実現する。

# 設計思想

スキルツリーは「成長の分岐化」を担う。すべて習得できると個性がなく、厳しすぎると選択ミスが致命的。リセット可能にすることで、試行錯誤を促し、最適解への到達を支援する。

# 主要機能

- スキルポイント: レベルアップで獲得
- スキルツリー構造: 分岐と前提条件
- アクティブスキル: 手動発動の特殊技
- パッシブスキル: 常時効果の能力強化
- シナジー: スキル間の相乗効果
- リセット機能: ポイントの振り直し
