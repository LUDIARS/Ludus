# 目的

クリア後も継続する目標を提供し、長期的なプレイ動機を維持する。

# 設計思想

難易度階層は「垂直方向の進行」を作る。ストーリークリアで終わりでなく、より強い敵と戦うためにより良い装備を集める。無限に続く階層で、理論上の終わりがない目標を提供する。

# 主要機能

- 難易度レベル: ノーマル、ハード、インフェルノなど
- 敵の強化: HP、ダメージの倍率増加
- 報酬の向上: 高難易度ほど良いドロップ
- グレーターリフト: 無限に上昇する難易度
- リーダーボード: 到達階層の競争
- シーズン制: 定期的なリセットと再挑戦
