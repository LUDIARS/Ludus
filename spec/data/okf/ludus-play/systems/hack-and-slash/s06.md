# 目的

ダメージタイプの多様性を提供し、敵への相性と戦略を生む。

# 設計思想

属性システムは「戦術的多様性」を生む。物理のみだと単調で、属性があることで敵との相性が生まれる。すべての敵に効く万能属性があると戦略性が失われるため、耐性と弱点のバランスが重要。

# 主要機能

- 基本属性: 炎、氷、雷、毒など
- 属性耐性: 敵ごとの弱点と抵抗
- 状態異常: 火傷、凍結、感電、中毒
- 属性変換: 物理ダメージを属性化
- 複合効果: 複数属性の同時付与
- 属性バランス: 純粋ビルドvs複合ビルド
