# 目的

拾った装備をさらに改良し、理想的な性能への到達を支援する。

# 設計思想

クラフトシステムは「運の悪さの救済」と「完璧への追求」を両立する。良いドロップが出なくても、クラフトで近づける。ただし、完全にドロップを無視できるほど強力だと、ルート収集の価値が薄れる。

# 主要機能

- 装備強化: レベルアップでステータス向上
- 再ロール: アフィックスの変更
- ソケット追加: 穴を開ける加工
- エンチャント: 特殊効果の付与
- 素材収集: クラフトに必要なアイテム
- 失敗リスク: 強化の成功率(一部のゲーム)
