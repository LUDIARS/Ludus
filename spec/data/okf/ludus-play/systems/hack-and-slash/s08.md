# 目的

友人との共闘を可能にし、社会的な楽しさと戦術の幅を広げる。

# 設計思想

マルチプレイは「社会的な持続性」を高める。ソロでも楽しいが、友人と遊ぶことで長期的なモチベーションが維持される。難易度スケーリングで、人数による有利不利を調整し、公平性を保つ。

# 主要機能

- パーティシステム: 2-4人での協力
- 難易度スケーリング: 人数に応じた敵強化
- ルート分配: 個別またはラウンドロビン
- 役割分担: タンク、DPS、サポート
- シナジースキル: 協力で発動する技
- トレード: アイテム交換
