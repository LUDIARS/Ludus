# 目的

見えない恐怖を作り出し、プレイヤーの想像力を刺激する。

# 設計思想

視界制限は「想像による恐怖の増幅」である。完全に見えると緊張感がなく、何も見えないと理不尽。ライトの範囲外にかすかに動くシルエットや、音だけが聞こえる状況が、最も恐怖を煽る。

# 主要機能

- 暗闇レベル: 環境光の段階的な暗さ
- 懐中電灯/光源: 限られた照明範囲
- バッテリー管理: 光源の使用時間制限
- 視界範囲: ライトの到達距離と広がり
- 影の濃さ: 暗部の完全な黒さ
- 視覚エフェクト: グレイン、ビネット効果
