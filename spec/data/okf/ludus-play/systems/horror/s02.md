# 目的

聴覚を通じて恐怖を演出し、見えない脅威の存在を示唆する。

# 設計思想

音響は「見えない情報の伝達」である。遠くの足音は警告、近くの呼吸音は緊迫、突然の静寂は何かが起きる前触れ。ヘッドホン推奨の3Dオーディオで、没入感と方向感覚を最大化する。

# 主要機能

- 環境音: きしむ床、風の音、水滴
- 方向性音響: 3Dオーディオで位置特定
- 足音追跡: 敵の接近を音で察知
- 心拍音: プレイヤーの緊張状態表現
- 突発音(ジャンプスケア): 予測不能な大音量
- 静寂: 音がない恐怖の演出
