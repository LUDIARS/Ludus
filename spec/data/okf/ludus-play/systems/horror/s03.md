# 目的

プレイヤーを追い詰める知的な脅威を作り、逃走の緊張感を提供する。

# 設計思想

追跡者AIは「捕食者と獲物の関係」を作る。完全ランダムだと対策不能で理不尽、完全固定だとパターン暗記ゲーム。プレイヤーの行動に反応しつつ、予測可能な要素を残すバランスが重要。

# 主要機能

- 巡回パターン: 予測可能な移動経路
- 視界/聴覚範囲: 検知される条件
- 追跡モード: 発見後の執拗な追跡
- 見失いメカニクス: 隠れて振り切る
- 学習AI: プレイヤーの隠れ場所を記憶
- 複数追跡者: 挟み撃ちの恐怖
