# 目的

戦えない状況での生存手段を提供し、静的な緊張感を作る。

# 設計思想

隠れるシステムは「受動的な恐怖」を生む。アクション的な逃走と対照的に、動けない状況での無力感。敵が近づく足音、扉を開ける音、隠れ場所の前を通り過ぎる瞬間が、最高潮の緊張を作る。

# 主要機能

- 隠れ場所: ロッカー、ベッド下、クローゼット
- 息を潜める: ボタン長押しで音を消す
- 視線管理: 隠れながら外を覗く
- 発見判定: 敵の視界内での検出
- 隠れ時間制限: 長時間は不可能(息切れなど)
- 複数人での隠れ: 狭い場所での共有
