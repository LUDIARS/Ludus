# 目的

精神的ダメージを可視化し、恐怖体験が累積する仕組みを作る。

# 設計思想

正気度は「恐怖の定量化」である。物理的なダメージと別に、精神的な消耗を管理させる。低正気度時の幻覚で、プレイヤーが現実と虚構を区別できなくなる混乱が、ホラーの深みを生む。

# 主要機能

- 正気度ゲージ: 精神状態の数値化
- 減少トリガー: 恐怖体験、死体発見、敵遭遇
- 回復手段: 安全地帯、アイテム、光
- 低正気度効果: 幻覚、画面歪み、幻聴
- 狂気状態: 極端に低下時の制御不能
- 視覚的フィードバック: 画面効果で状態表現
