# 目的

戦闘を最終手段にし、温存と使用のジレンマを作る。

# 設計思想

リソース制限は「無力感の演出」である。豊富な弾薬があればアクションゲームになり、恐怖が薄れる。わずかな弾数で「この敵を倒すべきか、逃げるべきか」と悩ませることで、戦略的緊張を作る。

# 主要機能

- 弾薬の希少性: 見つかる弾数が限定的
- 武器の選択: 銃、近接武器、使い捨て
- 耐久度: 武器の劣化と破損
- 回復アイテムの不足: 薬や包帯が貴重
- セーブポイントの制限: リボンやテープの消費
- インベントリ制限: 持てる量が少ない
