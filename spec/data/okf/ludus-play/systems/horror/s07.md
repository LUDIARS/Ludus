# 目的

予測不能な驚愕を提供し、瞬間的な恐怖を演出する。

# 設計思想

ジャンプスケアは「瞬間的な恐怖」を担う。多用すると慣れて効果が薄れ、使わないと緊張感が弱い。本物(敵)とフェイク(猫が飛び出すなど)を混在させ、プレイヤーを常に警戒させる。

# 主要機能

- 突発的出現: 予告なしの敵出現
- 音響の急変: 静寂から急激な大音量
- 視覚的ショック: 画面いっぱいの顔や血
- フェイク要素: 驚かせるが無害な演出
- タイミング制御: プレイヤーの油断を狙う
- 頻度調整: 多用しすぎない配慮
