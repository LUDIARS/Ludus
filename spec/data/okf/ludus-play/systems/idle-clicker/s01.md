# 目的

プレイヤーが操作しなくても進行し、忙しい人でも楽しめる体験を提供する。

# 設計思想

自動進行は「時間を味方にする」設計。アクティブプレイを要求しないため、忙しい社会人や学生でも継続できる。放置上限で「定期的なログイン」を促しつつ、長時間不在でも損失が大きすぎない配慮。

# 主要機能

- 自動戦闘: AI操作での敵撃破
- 放置報酬: オフライン時間の収益蓄積
- 上限時間: 最大12-24時間分まで
- 加速アイテム: 放置速度の倍化
- 収益の自動収集: ログイン時に一括受取
- 進行状況: どこまで進んだか表示
