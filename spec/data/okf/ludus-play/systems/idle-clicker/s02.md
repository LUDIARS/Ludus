# 目的

数値の急激な成長を提供し、成長の爽快感を演出する。

# 設計思想

指数関数的成長は「終わりなき進歩」を作る。線形成長だとすぐに頭打ちだが、倍々ゲームで常に「次の桁」を目指せる。転生システムで、リセットが後退でなく「より速く進むための投資」になる。

# 主要機能

- 収益の倍増: アップグレードで2倍、10倍、100倍
- 大きな数値: million、billion、trillion表記
- インフレ設計: 後半は天文学的数値
- 転生/リセット: 全リセットで永続ボーナス
- プレステージ通貨: リセット時の特別通貨
- 成長の視覚化: グラフや数値の急上昇
