# 目的

収益の使い道を提供し、投資判断と最適化の楽しさを生む。

# 設計思想

アップグレードシステムは「資源配分の最適化」を要求する。すべてを均等に強化するか、一点集中するか。コストの増加曲線で、「今買うか、貯めて後で買うか」の判断を迫る。

# 主要機能

- 生産施設: クリック収益の増加
- 自動生産: 放置収益の向上
- 効率アップグレード: コスパの改善
- 新機能解放: 新しい収益源の追加
- 段階的強化: レベル10、25、50で大幅向上
- コスト増加: 次のレベルが徐々に高額化
