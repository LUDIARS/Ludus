# 目的

長期的な進行感を提供し、リセットに意味を持たせる。

# 設計思想

プレステージは「メタ進行」を作る。一度のプレイで終わりでなく、リセットして強化された状態で再挑戦。各周回が短くなり(1週目10時間、2週目5時間、3週目2時間)、テンポが速くなる爽快感。

# 主要機能

- 全リセット: レベルと収益を0に戻す
- 永続ボーナス: リセット後も残る強化
- プレステージ通貨: 特別なアップグレード用
- 倍率向上: 次の周回が数倍速く進む
- 転生の閾値: 一定進行後に解放
- 複数回転生: 何度でも繰り返し可能
