# 目的

多様な収益源を提供し、編成と戦略の要素を加える。

# 設計思想

ヒーローシステムは「キャラクター性の追加」である。数値だけだと無機質だが、個性あるキャラがいることで愛着が湧く。各ヒーローの特性(早いが弱い、遅いが強い)で、戦略的選択を生む。

# 主要機能

- ヒーロー雇用: 通貨でキャラ獲得
- 自動攻撃: 各ヒーローが独自に稼ぐ
- スキル: 特殊効果や倍率向上
- レベルアップ: 個別の成長
- シナジー: 複数ヒーローの組み合わせ
- コスト増加: 後半ほど高額なヒーロー
