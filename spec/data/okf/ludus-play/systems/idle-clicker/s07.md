# 目的

長期的な目標を設定し、達成による報酬と満足感を提供する。

# 設計思想

アチーブメントは「マイルストーンの設定」である。自然にプレイしていれば達成できる目標で、プレイヤーに方向性を示す。隠し実績は発見の楽しさを提供し、完全達成は究極の目標となる。

# 主要機能

- 段階的目標: 1000匹撃破、100万ゴールド稼ぐなど
- 隠し実績: 特定条件での解放
- 報酬: 達成で通貨やボーナス
- 進捗表示: 現在何%達成か
- 完全達成報酬: 全実績で特別ボーナス
- カテゴリ分類: 戦闘、収集、成長など
