# 目的

特定能力の獲得まで進めない障害を配置し、段階的な世界開放を実現する。

# 設計思想

能力ゲートは「成長の可視化」を担う。新能力獲得は単なるステータス上昇でなく、「行けなかった場所に行ける」という明確な変化。色分け(青は水中、赤は耐熱など)で、必要能力を直感的に示す。

# 主要機能

- 能力依存の障害: 高い壁、水中、高熱エリアなど
- 必要能力: 二段ジャンプ、ダッシュ、水泳など
- 複数ルート: 異なる能力での到達方法
- 視覚的明示: 進めない理由が明確
- 記憶の促進: 「ここは後で戻ろう」
- オプション要素: 必須でない隠しエリア
