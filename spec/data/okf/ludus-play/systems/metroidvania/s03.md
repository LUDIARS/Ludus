# 目的

過去のエリアに戻る動機を作り、マップ全体の利用価値を高める。

# 設計思想

バックトラッキングは「世界の深み」を作る。一方通行だと通過するだけで終わるが、何度も戻ることで親しみが湧く。ただし、単なる往復作業にならないよう、ショートカットで効率化する。

# 主要機能

- 新能力での再探索: 以前は行けなかった場所
- ショートカット開通: 戻りやすさの向上
- 敵の再出現: 経験値やアイテムのファーム
- 変化する環境: イベント後の状態変化
- 隠しアイテム: 見落とした宝箱や強化
- クエストNPC: 特定アイテムを要求
