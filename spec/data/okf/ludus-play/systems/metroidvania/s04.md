# 目的

新しい移動手段や攻撃方法を段階的に獲得し、成長を実感させる。

# 設計思想

能力アンロックは「成長の階段」を作る。最初は基本移動のみ、徐々に空中移動、壁走りなど立体的に。各能力が「新しい遊び」を提供し、単調さを防ぐ。

# 主要機能

- 移動能力: 二段ジャンプ、壁蹴り、ダッシュ、飛行
- 環境対応: 水泳、耐熱スーツ、重力操作
- 攻撃能力: 新武器、チャージ攻撃、特殊弾
- ユーティリティ: マップ開示、敵スキャン、テレポート
- 段階的強化: 同じ能力の上位版
- 必須vs任意: ストーリー進行に必要かどうか
