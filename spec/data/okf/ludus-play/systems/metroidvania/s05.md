# 目的

プレイヤーに探索順序の選択を与え、自分なりの攻略ルートを作らせる。

# 設計思想

非線形進行は「プレイヤーの創造性」を尊重する。完全に線形だと一本道で退屈、完全自由だと迷子になる。主要ルートは明示しつつ、探索で別ルートを発見できる設計が理想。

# 主要機能

- 複数ルート: 目的地への異なる道筋
- スキップ可能: 一部のボスやエリアを飛ばせる
- シーケンスブレイク: 意図外の順序での進行
- 難易度の選択: 難しいルートと簡単なルート
- 早期アクセス: 本来後の装備を先に取得
- RTA要素: スピードランでの最適化
