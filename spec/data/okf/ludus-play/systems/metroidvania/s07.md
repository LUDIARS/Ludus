# 目的

探索の合間に戦闘の緊張感を提供し、能力習得の試練とする。

# 設計思想

ボス戦は「探索の区切り」を作る。常に探索だけだと単調で、ボスが節目となる。新能力習得直後のボスで、その能力の使い方を教える設計が効果的。

# 主要機能

- パターン学習: ボスの攻撃パターン認識
- 弱点システム: 特定武器や戦術が有効
- 多段階変化: 体力減少で行動変化
- 能力の試練: 新能力を使わせる設計
- ボス部屋: 専用のアリーナ
- 報酬: 撃破後の能力やアイテム
