# 目的

広大な世界での迷子を防ぎ、探索の進行状況を可視化する。

# 設計思想

マップシステムは「探索の羅針盤」である。マップなしだと迷いやすく、完全表示だと探索の価値が薄れる。訪れた場所のみ表示し、未探索エリアを「霧」で示すことで、次の目標を暗示する。

# 主要機能

- 自動マッピング: 訪れた場所の記録
- マップ取得: 各エリアのマップアイテム
- 未探索の表示: 行っていない場所の明示
- セーブポイント表示: 休憩場所の位置
- アイテムマーカー: 取得済みと未取得の区別
- 完了率表示: 探索の進捗パーセント
