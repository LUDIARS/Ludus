# 目的

多様なプレイスタイルを提供し、役割分担とカウンター関係を作る。

# 設計思想

ヒーローシステムは「非対称バランス」を作る。全員が同じ能力だと単調で、個性が強すぎると不公平。100体以上のヒーローがいても、勝率50%前後に収まるバランス調整が理想。

# 主要機能

- ヒーローロール: キャリー、サポート、タンク、メイジなど
- 固有スキル: 各ヒーロー3-4つの特殊能力
- パッシブ能力: 常時発動の固有効果
- アルティメット: 強力な必殺技
- ステータス: HP、マナ、攻撃力、防御力、移動速度
- ヒーローピック: 試合前の選択とバン
