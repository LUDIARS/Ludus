# 目的

3レーン構造で戦場を分割し、戦略的な配置と移動を要求する。

# 設計思想

マップ構造は「空間的な戦略性」を定義する。3レーンは分散と集中のバランスで、全員が一箇所にいると他が手薄になり、分散しすぎると数的不利。レーンの非対称性(トップが長い、ボットが短いなど)が戦略の幅を広げる。

# 主要機能

- 3レーン: トップ、ミッド、ボット(一般的)
- ジャングル: レーン間の中立エリア
- タワー/タレット: 各レーンの防衛施設
- ミニオン/クリープ: 自動で前進する雑魚
- ネクサス/エンシェント: 破壊目標の本拠地
- 霧戦(Fog of War): 視界外の不可視化
