# 目的

ミニオン撃破によるゴールド獲得を通じて、経済格差を作る。

# 設計思想

ラストヒットは「機械的技術の試金石」である。単に敵を倒すだけでなく、ミニオンの体力を見てとどめのタイミングを計る。相手にハラスされながらのラストヒットが、レーン戦の核心技術。

# 主要機能

- ラストヒット: とどめでゴールド獲得
- 経験値共有: 近くにいれば範囲内で獲得
- ゴールド配分: キルしたプレイヤーが独占
- CSカウント: クリープスコアの累積
- デナイ: 味方ミニオンを倒して経験値阻止(Dota系)
- ウェーブ管理: ミニオンの位置制御
