# 目的

ゴールドでアイテムを購入し、ヒーローの能力をカスタマイズする。

# 設計思想

アイテムシステムは「戦略的カスタマイズ」を可能にする。固定ビルドだと単調で、完全自由だと初心者が迷う。コアアイテム(必須)とシチュエーショナルアイテム(状況次第)のバランスが重要。

# 主要機能

- ショップ: 拠点またはフィールドでの購入
- アイテムカテゴリ: 攻撃、防御、ユーティリティ
- アイテム合成: 複数の小物から強力な装備
- 推奨ビルド: 初心者向けの標準構成
- 状況対応: 敵構成に応じた柔軟な選択
- アクティブアイテム: 使用効果のある装備
