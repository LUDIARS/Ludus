# 目的

試合中の成長を通じて、序盤から終盤への変化を作る。

# 設計思想

レベルシステムは「試合内の成長曲線」を作る。序盤は弱く慎重、中盤でスキルが揃い、終盤は全員が強力。パワースパイク(レベル6でアルティメット習得など)が、積極性のタイミングを決める。

# 主要機能

- 経験値獲得: ミニオン、ジャングル、キルで蓄積
- レベルキャップ: 最大レベル(通常18-25)
- スキルポイント: レベルごとに獲得
- スキル強化: ポイント配分で能力向上
- アルティメット解放: 特定レベルで習得
- タレント選択: 特定レベルでの分岐(一部のゲーム)
