# 目的

レーン以外の経験値源とオブジェクト管理を提供する。

# 設計思想

ジャングルシステムは「第4の戦場」を作る。レーン3つだけでは単調なため、ジャングルが機動戦と奇襲の場になる。エピックモンスターは「集団戦の動機」で、全員が集まる理由を提供する。

# 主要機能

- 中立キャンプ: ジャングル内のモンスター群
- リスポーン時間: 一定時間後の再出現
- バフモンスター: 特殊効果を付与
- エピックモンスター: 強力で全体に影響(ドラゴン、バロンなど)
- ジャングラー役: 専門ポジション
- スマイト: ジャングル専用の即死スキル
