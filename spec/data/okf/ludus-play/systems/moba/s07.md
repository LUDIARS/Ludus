# 目的

5vs5の大規模戦闘を通じて、チームワークと役割分担を試す。

# 設計思想

集団戦は「MOBAの華」である。個人技だけでなく、5人の連携が勝敗を分ける。イニシエート(開戦)、フォロー(追撃)、ディスエンゲージ(撤退)の判断が、チームの成熟度を示す。

# 主要機能

- エンゲージ: 戦闘開始の仕掛け
- フォーカスターゲット: 集中攻撃の対象選択
- ポジショニング: 前衛と後衛の配置
- CC(クラウドコントロール): スタン、スロー、ルートなど
- AOE(範囲攻撃): 複数を巻き込む技
- ピール: 味方キャリーの保護
