# 目的

最終目標への進軍を管理し、勝利条件への道筋を作る。

# 設計思想

プッシュシステムは「段階的な目標」を作る。いきなりネクサスは破壊できず、タワー→バラック→ネクサスと順番に進む。これが試合の「章」を作り、序盤・中盤・終盤の区切りを生む。

# 主要機能

- ミニオンウェーブ: 定期的な雑魚の出現
- タワー攻城: 防衛施設の破壊
- バラック/インヒビター: 破壊でスーパーミニオン
- ネクサス破壊: 勝利条件
- スプリットプッシュ: 別レーンでの単独進軍
- バックドア: ミニオンなしでの攻城(制限あり)
