# 目的

パズル操作を戦闘の核とし、プレイヤースキルを直接反映させる。

# 設計思想

ドロップ消しは「操作技術の戦闘化」である。運だけのガチャゲーと違い、パズルスキルが勝敗を分ける。移動時間制限(4-5秒)で焦りと集中を強いつつ、スキルストップで上級者向けの高度な操作を可能にする。

# 主要機能

- ドロップ移動: 制限時間内の自由スライド
- 連鎖判定: 消去後の落下で追加マッチ
- 同時消し: 複数箇所の同時マッチ
- 最小マッチ数: 通常3個、特殊で4-5個
- ドロップ種類: 火水木光闇+回復
- スキルストップ: 移動中の一時停止
