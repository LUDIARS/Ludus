# 目的

複数消しを報酬化し、高度なパズル技術に価値を与える。

# 設計思想

コンボシステムは「技術の定量化」である。3コンボと10コンボで与ダメージが数倍〜数十倍変わることで、パズルの上達が明確に報われる。敵のコンボ吸収ギミックは、「高すぎても低すぎてもダメ」という調整を要求する。

# 主要機能

- コンボカウント: 同時消し数の計測
- ダメージ倍率: コンボ数に応じた増加
- 属性倍率: リーダースキルでの強化
- コンボ吸収: 特定コンボ数以上無効化(敵ギミック)
- 最大倍率: 理論上の最高ダメージ
- 表示演出: コンボ数の派手な表示
