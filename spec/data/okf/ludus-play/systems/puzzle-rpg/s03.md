# 目的

キャラクター収集欲を刺激し、多様な編成可能性を提供する。

# 設計思想

収集システムは「RPG要素の中核」である。同じモンスターでも進化先が複数あることで、戦略的選択が生まれる。属性とタイプの組み合わせで、編成制限ダンジョン(火属性のみ、ドラゴンタイプのみなど)への対応が必要になる。

# 主要機能

- レアガチャ: 魔法石消費での召喚
- レアリティ: 星3-7までの階層
- 属性: 火水木光闇の5属性
- タイプ: ドラゴン、神、悪魔、バランスなど
- 進化素材: 特定モンスターでの進化
- 究極進化: 複数の進化先分岐
