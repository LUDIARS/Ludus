# 目的

パーティ構築の戦略性を提供し、所持モンスターの価値を最大化する。

# 設計思想

編成システムは「パズル要素とRPG要素の接続点」である。リーダースキルで倍率が決まり、サブで補助や追加火力を担う。フレンドシステムで、未所持の強リーダーも借りられる社交性を持たせる。

# 主要機能

- リーダースキル: 全体への恒久効果
- サブメンバー: 4体のサポート枠
- フレンドリーダー: 他プレイヤーの借用
- 覚醒スキル: 個別の特殊能力
- コスト制限: 高レアは重い、低レアは軽い
- スキル継承: 別モンスターのスキル装備
