# 目的

パズル以外の戦術手段を提供し、戦況を覆す逆転要素を作る。

# 設計思想

スキルシステムは「パズル失敗の保険」である。運悪く必要な色が来なくても、変換スキルで生成できる。ただし、ターン制限で無限使用はできず、「ここぞ」という時の判断を要求する。

# 主要機能

- スキルターン: 使用までの待機ターン
- 効果種類: 変換、エンハンス、防御、回復
- ドロップ変換: 特定色を別色に変更
- 敵スキル遅延: 敵の行動を遅らせる
- スキルターン短縮: 覚醒スキルでの加速
- 継承スキル: 追加スキルの装備
