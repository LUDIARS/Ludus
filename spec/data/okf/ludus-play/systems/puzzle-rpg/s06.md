# 目的

段階的な難易度提供と、多様な挑戦目標を設定する。

# 設計思想

ダンジョン構造は「目標の段階化」を担う。通常ダンジョンは初心者向け、テクニカルは上級者向け、スペシャルは期間限定の変化。各ダンジョンに明確な報酬(進化素材、経験値、コイン)を設定し、周回の動機を作る。

# 主要機能

- 通常ダンジョン: ストーリー進行
- テクニカルダンジョン: 高難易度挑戦
- スペシャルダンジョン: 期間限定
- バトル数: 通常5-10バトル
- ボスフロア: 最終階の強敵
- 先制攻撃: 開幕ダメージや状態異常
