# 目的

単純なパズルに戦術的思考を要求し、編成や戦略の重要性を高める。

# 設計思想

敵ギミックは「パズルだけで勝てない」状況を作る。属性吸収があれば多色編成が必要、ダメージ吸収があれば火力調整が必要。これにより、パズルスキル以外に編成知識も重要になる。

# 主要機能

- 属性吸収: 特定属性攻撃を無効化
- ダメージ吸収: 一定値以上を無効化
- 先制攻撃: ターン開始前の攻撃
- 根性: HP1で耐える
- 状態異常: 操作時間短縮、ドロップロック
- 割合ダメージ: 現在HPの%攻撃
