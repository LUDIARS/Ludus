# 目的

他プレイヤーとの共闘を提供し、社会的な楽しさを加える。

# 設計思想

協力プレイは「ソーシャル要素の強化」である。ソロ主体のゲームだが、協力モードで他者とのつながりを作る。スタミナ分担(ソロ50消費、マルチ各自17消費など)で、効率的な周回手段として機能する。

# 主要機能

- 3人協力: 最大3人での挑戦
- 交互操作: 順番にパズル
- スタミナ分担: 各自が一部負担
- 役割分担: 火力、回復、サポート
- 専用ダンジョン: マルチ限定ステージ
- 報酬ボーナス: ソロより良い報酬
