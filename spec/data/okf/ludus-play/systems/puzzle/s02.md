# 目的

特定のパターンを揃えることで要素を消去し、得点と連鎖を生む。

# 設計思想

マッチングは「パターン認識の報酬化」である。3つマッチが基本で、それ以上は特別な報酬。連鎖はスキルと運のバランスで、完全制御可能だと機械的になり、完全ランダムだと不公平に感じる。

# 主要機能

- マッチング条件: 3つ以上、4つ、L字型など
- 消去判定: マッチ検出アルゴリズム
- 連鎖/コンボ: 消去後の落下で新たなマッチが発生
- 特殊ピース生成: 4つ以上で爆弾、5つでレインボーなど
- 消去エフェクト: アニメーションと音による満足感
