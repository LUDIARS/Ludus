# 目的

プレイヤーがパズル要素を操作する方法を定義し、直感的な入力を提供する。

# 設計思想

操作システムは「パズルのインターフェース」である。制約が強いほど難易度は上がるが、理不尽にならないよう注意。スワップは双方向性を保ち、スライドは自由度が高い。入力レスポンスの速さが操作感を左右する。

# 主要機能

- スワップ: 隣接する2つのピースを入れ替え
- スライド: ピースを空いた場所に移動
- 回転: テトリスのようなピース回転
- ドラッグ: ピースを掴んで任意の位置へ移動
- 入力の取り消し: 直前の操作をアンドゥ
