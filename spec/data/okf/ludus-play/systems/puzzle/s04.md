# 目的

ピース消去後の空間を埋め、継続的なゲームプレイを可能にする。

# 設計思想

重力システムは「パズルの新陳代謝」を担う。落下速度が速すぎると次の手を考える時間がなく、遅すぎるとテンポが悪い。連鎖を生む可能性と、プレイヤーの予測可能性のバランスが重要。

# 主要機能

- 上から落下: 消去された場所に上のピースが落ちる
- 新規生成: 最上段に新しいピースが出現
- 落下アニメーション: スムーズな移動表現
- 落下速度: 通常と高速の切り替え
- 特殊落下: 横方向、斜め、ランダムな落下パターン
