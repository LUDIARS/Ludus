# 目的

明確な勝利条件と制約を設け、パズルに目的と緊張感を与える。

# 設計思想

制限システムは「パズルのゲーム化」を実現する。無制限だと漫然としたプレイになり、厳しすぎるとストレスになる。複数の目標タイプで難易度とバラエティを調整する。

# 主要機能

- 移動回数制限: 限られた手数でクリア
- 時間制限: タイムアタック要素
- 目標スコア: 一定点数の達成
- 特定ピース消去: 指定された数のピースを消す
- 障害物除去: 特殊なブロックを破壊
