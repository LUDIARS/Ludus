# 目的

行き詰まった時の救済手段を提供し、プレイヤーの学習を支援する。

# 設計思想

ヒントシステムは「救済と学習の両立」を目指す。無制限だと緊張感が失われ、なさすぎると初心者が離脱する。使用にコスト(ゴールド、広告視聴など)を設けることで、戦略的な選択にする。

# 主要機能

- ヒント表示: 可能な移動の一つを点滅表示
- シャッフル: 全ピースの再配置
- 特殊アイテム: 任意のピース消去、色変更など
- アンドゥ: 直前の移動を取り消し
- 使用制限: ヒントの回数制限やコスト
