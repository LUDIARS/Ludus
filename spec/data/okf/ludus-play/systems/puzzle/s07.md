# 目的

プレイヤーの技術を数値化し、リプレイ動機と競争心を刺激する。

# 設計思想

スコアシステムは「技術の定量化」である。単純な消去数だけでなく、コンボや効率性を評価することで、戦略的な深みを生む。星3つ(60%, 80%, 100%)のような段階的目標で、プレイヤーのスキルレベルに応じた達成感を提供する。

# 主要機能

- 基本スコア: ピース消去ごとの得点
- コンボ倍率: 連続消去でスコア増加
- 残り手数ボーナス: 早くクリアすると追加点
- 星評価: 1-3星で達成度を表示
- リーダーボード: 他プレイヤーとの比較
