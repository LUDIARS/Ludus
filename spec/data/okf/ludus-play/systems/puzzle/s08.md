# 目的

通常のルールを超えた特殊能力を提供し、戦略の幅を広げる。

# 設計思想

パワーアップは「救済と戦略の両立」を担う。強力すぎるとゲームバランスが崩れ、弱すぎると使う価値がない。限られた回数や高コストで、「ここぞという時」に使う特別感を演出する。

# 主要機能

- ゲーム開始ブースター: 開始時の有利な状態
- ゲーム中パワーアップ: プレイ中に使える特殊能力
- ランダムドロップ: 盤面に出現する特殊ピース
- 購入システム: ゲーム内通貨での獲得
- 効果の種類: 爆弾、レインボー、時間延長など
