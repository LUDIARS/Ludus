# 目的

車両の挙動を制御し、リアルさと操作の楽しさのバランスを取る。

# 設計思想

車両物理は「リアリズムとアーケード性のスペクトラム」上にある。完全リアルは難しすぎ、完全アーケードは浅い。ターゲット層に応じて、シミュレーション寄り(フォルツァ)かアーケード寄り(マリオカート)かを決定する。

# 主要機能

- 加速/減速: アクセルとブレーキの入力処理
- ステアリング: ハンドル角度と旋回半径
- グリップ/スリップ: タイヤと路面の摩擦
- ドリフト: 意図的なスライド制御
- ダウンフォース: 速度による車体の押さえつけ
- 重心/慣性: 車両の質量と重量配分
