# 目的

スピード感を増幅し、テクニックによる速度向上を可能にする。

# 設計思想

ドリフトシステムは「技術の報酬化」である。現実のレースではドリフトは遅いが、ゲームでは楽しさを優先してボーナスを与える。ゲージの溜まり方と消費のバランスで、リスクとリターンを調整する。

# 主要機能

- ドリフト開始: ブレーキ+ステアリングで横滑り
- ドリフト角度維持: カウンターステアで制御
- ドリフトゲージ: 時間や角度で溜まるメーター
- ブースト発動: ゲージ満タンで加速
- パーフェクトドリフト: 最適角度でボーナス
