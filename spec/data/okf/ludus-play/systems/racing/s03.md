# 目的

多様な走行環境を提供し、戦略的なライン取りを可能にする。

# 設計思想

コース設計は「リスクと報酬の配置」である。ヘアピン前の直線は追い越しポイント、狭いセクションは順位変動が少ない。理想的なレーシングラインと、危険だが速いラインを併存させることで、スキル差が出る。

# 主要機能

- コースレイアウト: 直線、カーブ、ヘアピン、S字
- 路面タイプ: アスファルト、ダート、氷、水たまり
- コース幅: 追い越し可能な広さの設計
- 高低差: 上り坂、下り坂、ジャンプ台
- ショートカット: リスクを伴う近道
- コース外判定: 逸脱時のペナルティ
