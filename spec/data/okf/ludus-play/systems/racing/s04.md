# 目的

レース中の相対位置を追跡し、競争状況を可視化する。

# 設計思想

順位システムは「競争の可視化」である。単に「2位」と表示するだけでなく、前後との差(+2.3秒、-0.8秒)を示すことで緊張感を高める。ゴーストカーは「見える目標」として機能し、上達の動機になる。

# 主要機能

- 現在順位: リアルタイムの順位表示
- ラップタイム: 周回ごとのタイム計測
- ベストラップ: 自己最速記録の保持
- セクションタイム: コース区間ごとの比較
- 順位変動通知: 追い越し/抜かれた時の表示
- ゴーストカー: 過去の自分や他者の走行記録
