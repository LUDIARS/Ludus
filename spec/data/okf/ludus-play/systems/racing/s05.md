# 目的

プレイヤーとAIの実力差を補正し、常に接戦を演出する。

# 設計思想

ラバーバンディングは「公平性と興奮の天秤」である。露骨すぎると「努力が無駄」と感じさせ、なさすぎると初心者が楽しめない。最後の1周だけ強化する、トップ3に入るまで補正するなど、段階的な適用が理想。

# 主要機能

- 動的難易度調整: プレイヤーの位置に応じてAI速度変化
- 追いつきやすさ: 大差がつくと後続が加速
- 逃げ切り防止: トップを走ると追手が速くなる
- ミス頻度調整: プレイヤーが後方だとAIがミスする
- 調整の透明性: 露骨に見えないよう自然に実装
