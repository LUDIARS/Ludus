# 目的

車両同士や障害物との接触を処理し、リスクと戦略を生む。

# 設計思想

衝突システムは「リスクの具現化」である。ダメージなしだと壁擦りが最速になり、厳しすぎると慎重すぎるプレイになる。リセット(軽微な衝突)とリスタート(大破)の間のバランスで、攻めと守りの選択を生む。

# 主要機能

- 衝突判定: 車両やコース境界との接触検出
- ダメージ蓄積: 衝突回数や強度で車両が劣化
- 速度ペナルティ: 衝突時の減速
- スピンアウト: 大きな衝撃で制御喪失
- 修復システム: ピットストップでの回復
- 視覚的ダメージ: 車体の凹みや傷
