# 目的

一時的な速度向上を提供し、戦術的な使用タイミングを要求する。

# 設計思想

ブーストシステムは「機会の均等化」を図る。常に最前列が有利だとつまらないが、後方が有利すぎると先行の意味がない。マリオカート型(後方に強アイテム)とフォルツァ型(スキルで稼ぐニトロ)は異なる哲学。

# 主要機能

- ニトロゲージ: 使用可能量の管理
- ブーストパッド: コース上の加速エリア
- アイテムボックス: ランダムなパワーアップ取得
- 使用時の効果: 速度上昇、無敵、武器など
- 回復メカニクス: 時間経過、ドリフト、ジャンプで回復
