# 目的

プレイヤーに最適な視界を提供し、速度感と制御性を両立する。

# 設計思想

カメラは「速度の伝達装置」である。3人称は全体が見えて初心者向き、1人称は没入感が高いが難しい。速度に応じたFOV拡大(周辺視野のブラー)で、実際より速く感じさせる錯覚を利用する。

# 主要機能

- 視点切り替え: 1人称、3人称(近/遠)、バンパー視点
- 動的カメラ: 速度に応じた画角変化
- ルックアラウンド: 周囲確認のための視点回転
- リプレイカメラ: レース後の演出用視点
- 手ぶれ/揺れ: スピード感を強調するエフェクト
- FOV調整: 視野角の変更
