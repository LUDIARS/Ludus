# 目的

同じ楽曲で複数の難易度を提供し、幅広い層に対応する。

# 設計思想

難易度システムは「階段状の成長」を作る。初心者向けは4分音符だけ、上級者向けは16分音符や32分音符の連打。同じ楽曲で複数譜面があることで、成長に応じて同じ曲を何度も楽しめる。

# 主要機能

- 難易度階層: Easy、Normal、Hard、Expert、Master
- ノーツ密度: 難易度による配置数
- 複雑なパターン: 同時押し、高速連打、複雑な動き
- レベル表記: 1-30などの数値
- 譜面製作: リズムに合わせた配置設計
- プレビュー: 事前の譜面確認
