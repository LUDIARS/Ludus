# 目的

プレイ可能楽曲を増やし、収集欲と多様性を提供する。

# 設計思想

楽曲収集は「コンテンツの拡張性」を担う。初期楽曲だけだとすぐ飽きるため、定期的な追加が重要。版権曲(アニソン、ボカロなど)はライセンス料が高いが集客力があり、オリジナル曲は低コストだが知名度が低い。

# 主要機能

- 楽曲購入: 個別またはパック単位
- ガチャ: ランダム楽曲獲得
- 無料楽曲: 基本セットの常設
- 期間限定: イベント楽曲の配信
- コラボ: アニメやゲームとのタイアップ
- 試聴機能: 購入前の一部プレイ
