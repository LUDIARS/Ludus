# 目的

音ゲーにRPG要素を加え、育成と編成の楽しさを提供する。

# 設計思想

キャラクターシステムは「音ゲーの拡張」である。純粋な音ゲーはスキル依存だが、キャラ育成要素を加えることで、リズムが苦手な人も楽しめる。スキルでスコアが上がるため、下手でもキャラ編成で補える救済措置。

# 主要機能

- キャラクターガチャ: ランダムでキャラ獲得
- スキル: スコアアップ、判定緩和など
- 編成: 5人程度のユニット構成
- レベル上げ: 経験値での成長
- 覚醒/限界突破: 同キャラ合成での強化
- イラスト/ボイス: キャラクター性の表現
