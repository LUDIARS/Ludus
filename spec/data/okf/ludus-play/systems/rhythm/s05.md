# 目的

視覚的な華やかさを提供し、ライブ体験の臨場感を演出する。

# 設計思想

ライブ演出は「音ゲーとアイドルゲームの融合」である。派手な演出はモチベーションを高めるが、ノーツが見づらくなるジレンマ。2Dモードや軽量モードで、プレイ重視と演出重視の選択を可能にする。

# 主要機能

- 3Dモデル: キャラクターのダンス
- カメラワーク: 動的な視点変更
- エフェクト: ノーツヒット時の派手な演出
- 背景: ステージや照明の変化
- 衣装変更: キャラの見た目カスタマイズ
- 軽量モード: 低スペック端末向け簡略化
