# 目的

プレイヤー間の競争を提供し、上達への動機を作る。

# 設計思想

ランキングシステムは「技術の可視化」である。音ゲーはスキル依存度が高いジャンルのため、上手い人が正当に評価される。リプレイ機能で上位者から学び、段位認定で中間目標を設定する。

# 主要機能

- グローバルランキング: 全プレイヤー中の順位
- フレンドランキング: 友人との比較
- ハイスコア: 自己ベストの記録
- リプレイ: 上位者のプレイ確認
- 段位認定: 特定スコアでの称号
- イベントランキング: 期間限定の競争
