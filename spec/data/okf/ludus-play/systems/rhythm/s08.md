# 目的

定期的な変化を提供し、コミュニティとの協力を促す。

# 設計思想

イベントシステムは「継続的なエンゲージメント」を作る。常設コンテンツだけだと飽きが来るため、2週間単位などで新イベント。協力プレイは音ゲーに社会性を追加し、一人プレイとは異なる楽しさを提供する。

# 主要機能

- ポイントイベント: 累積スコアで報酬
- ランキングイベント: 上位者への限定報酬
- 協力ライブ: 複数人での同時プレイ
- イベント限定楽曲: 期間中のみプレイ可能
- ミッションクリア: 特定条件達成で報酬
- 交換所: イベントptで限定アイテム
