# 目的

毎回異なるダンジョンやレベルを生成し、飽きのこない体験を提供する。

# 設計思想

プロシージャル生成は「無限のコンテンツ」を実現する。完全ランダムだと理不尽な配置(行き止まり、アイテムなし)になるため、制約と保証(必ず出口がある、最低限の装備は出る)が必要。

# 主要機能

- 部屋生成アルゴリズム: ランダムな配置と接続
- 通路の生成: 部屋間を繋ぐ経路
- シード値: 同じマップの再生成
- バイオーム: テーマ別のエリア(森、洞窟、城など)
- 配置ルール: 敵、アイテム、罠の適切な配置
- 保証要素: 必ず出現するアイテムや出口
