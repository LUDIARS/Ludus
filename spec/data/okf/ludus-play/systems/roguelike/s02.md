# 目的

死を永続的にし、一回のランの重みと緊張感を最大化する。

# 設計思想

パーマデスは「失敗の重み」を最大化する。ローグライク(完全リセット)は厳格で達成感が高く、ローグライト(一部引き継ぎ)は挫折を軽減する。メタ進行(死ぬたびに強化)で、長期的なモチベーションを維持する。

# 主要機能

- 完全リセット: 死亡で最初から
- 引き継ぎ要素: 永続的なアップグレード(ローグライト)
- セーブ不可: 中断は可能だが巻き戻し不可
- ワンライフ: 復活なし(または限定的)
- 進行のロック解除: 新キャラ、新アイテムの追加
- デスログ: 死因の記録と統計
