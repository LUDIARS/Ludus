# 目的

戦略的な思考時間を提供し、一手一手が重要な戦術ゲームを作る。

# 設計思想

ターン制は「思考のゲーム化」である(リアルタイムのローグライトもある)。敵の攻撃パターン、射程、移動速度を理解し、最適な位置と行動を選ぶ。1ターンのミスが死に直結する緊張感が、慎重なプレイを促す。

# 主要機能

- グリッドベース移動: マス目での位置管理
- 行動ポイント: 移動と攻撃のコスト
- 敵のターン: プレイヤー行動後に敵が動く
- 視界システム: 見えない敵は動かない
- ポジショニング: 位置取りが戦術を決める
- 状態異常: 毒、麻痺、出血などの継続効果
