# 目的

未知のアイテムに不確実性を持たせ、リスクとリターンの判断を要求する。

# 設計思想

アイテム識別は「情報の不完全性」を作る。すべて既知だと戦略が固定化し、完全ランダムだと運ゲームになる。識別アイテムの配置と、「試して分かる」リスクのバランスが重要。

# 主要機能

- 未識別状態: 拾った時は効果不明
- 識別方法: 使用、鑑定、店での確認
- ランダム付与: 同じ外見でも効果が異なる
- 呪いアイテム: 装備すると外せない負の効果
- ポーション/巻物: 飲む/読むまで分からない
- 識別の引き継ぎ: 次のランで記憶(オプション)
