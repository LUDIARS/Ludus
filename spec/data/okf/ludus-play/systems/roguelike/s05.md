# 目的

長期的な計画性を要求し、無限の探索を防ぐ時間制限を作る。

# 設計思想

飢餓システムは「探索の時間制限」である。無限に探索できると最強装備を揃えられるため、食料制限で前進を促す。厳しすぎると探索できず、緩すぎると意味がないバランス調整が鍵。

# 主要機能

- 空腹ゲージ: ターン経過で減少
- 食料アイテム: パンや肉での回復
- 飢餓ペナルティ: 空腹時のHP減少や能力低下
- 食料の希少性: 十分だが無駄遣いできない量
- 腐敗システム: 時間経過で食料劣化
- 満腹度ボーナス: 満腹時の能力向上
