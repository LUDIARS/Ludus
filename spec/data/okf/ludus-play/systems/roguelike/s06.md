# 目的

一回のラン内での成長を提供し、序盤から終盤への変化を作る。

# 設計思想

成長システムは「一回のランの弧」を作る。弱い状態から始まり、レベルアップで強くなり、最終ボスに挑む物語。ランダム要素(どの装備が出るか)と選択(どう成長するか)の組み合わせが、毎回異なるビルドを生む。

# 主要機能

- 経験値獲得: 敵撃破で蓄積
- レベルアップ: HP、攻撃力、防御力の上昇
- スキル習得: 特殊能力の解放
- ステータス配分: 自由な成長方向
- クラス/職業: 戦士、魔法使い、盗賊など
- 進化/転職: 上位クラスへの変化
