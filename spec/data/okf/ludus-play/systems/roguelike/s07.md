# 目的

死亡後も進歩を感じさせ、長期的なモチベーションを維持する(ローグライト)。

# 設計思想

メタ進行は「長期的な成長曲線」を作る(純ローグライクにはない)。強くなりすぎるとヌルゲー化するため、永続強化は控えめに。スキルでクリアできるバランスを保ちつつ、苦手な人も繰り返せば勝てる設計。

# 主要機能

- 通貨の蓄積: 死んでも持ち越せるコイン
- 永続アップグレード: 基礎能力の強化
- キャラ解放: 新しいプレイスタイル
- アイテムプール拡張: 新装備の追加
- ショートカット: 序盤スキップの解放
- ストーリー進行: 繰り返しで物語が進む
