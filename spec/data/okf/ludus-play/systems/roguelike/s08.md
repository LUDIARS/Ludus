# 目的

アイテムやスキルの組み合わせで強力なビルドを作る楽しみを提供する。

# 設計思想

シナジーシステムは「創発的なゲームプレイ」を生む。開発者が意図しない組み合わせで、プレイヤーが超強力なビルドを発見する。ランダム要素があるため、毎回同じビルドは作れず、手札での最適解を探す楽しさ。

# 主要機能

- アイテム効果の重複: 同系統の強化
- 相乗効果: 特定の組み合わせでボーナス
- タグシステム: 炎、毒、雷などの属性
- トランスフォーム: 特定の組で完全変化
- パッシブの累積: 小さな効果の積み重ね
- ユニークビルド: 極端な特化構成
