# 目的

プレイヤーの進行を数値化し、成長の実感と達成感を提供する。

# 設計思想

レベルシステムは「時間投資の見える化」である。急激な成長は初期の達成感を高めるが、後半の停滞を招く。対数カーブや段階的な必要経験値で、常に「もう少しで次のレベル」と感じさせるバランスが理想。

# 主要機能

- 経験値獲得: 敵撃破、クエスト完了、探索で獲得
- レベルアップ: 累積経験値が閾値に達すると上昇
- 経験値カーブ: レベルが上がるほど必要経験値が増加
- レベル差補正: 格下の敵からの経験値減少
- パーティ経験値分配: 複数キャラへの分配または共有
