# 目的

キャラクターの能力を数値化し、成長の方向性と戦略的選択を提供する。

# 設計思想

ステータスシステムは「キャラクターの個性化」を実現する。単純な数値上昇だけでなく、ステータス間の相互作用(攻撃力と命中率のバランスなど)が戦略の深みを生む。振り直し可能性で試行錯誤を許容するか、不可逆で緊張感を高めるかは設計思想次第。

# 主要機能

- 基本ステータス: HP、MP、攻撃力、防御力、速度など
- 派生ステータス: クリティカル率、回避率、命中率
- ステータスポイント配分: レベルアップ時の自由割り振り
- 装備によるステータス変化: 武器防具の効果
- バフ/デバフ: 一時的なステータス変動
