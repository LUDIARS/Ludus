# 目的

通常攻撃以外の多様な行動を提供し、戦術的選択肢を広げる。

# 設計思想

スキルシステムは「選択の重み」を作る。すべてのスキルを習得できると選択の意味が薄れ、少なすぎると多様性が失われる。分岐や相互排他的な選択で、プレイヤーごとに異なるビルドが生まれる設計が理想。

# 主要機能

- スキルツリー: 段階的な習得と分岐選択
- アクティブスキル: 手動発動の特殊技
- パッシブスキル: 常時発動の能力強化
- スキルポイント: レベルアップで獲得し習得に使用
- クールダウン: スキル使用後の再使用待機時間
- コスト: MP、スタミナ、アイテムなどの消費
