# 目的

戦略的思考の時間を確保し、アクション性よりも判断力を重視する。

# 設計思想

ターン制は「チェスのような戦略性」を提供する。完全ターン制は初心者に優しいが単調になりやすく、ATBは緊張感があるが焦りを生む。速度によるターン順の可視化で、戦術的な読み合いが生まれる。

# 主要機能

- ターン順管理: 速度ステータスで行動順を決定
- ATB(アクティブタイムバトル): リアルタイムでゲージが溜まる
- コマンド選択: 攻撃、防御、スキル、アイテムから選択
- ターゲット選択: 単体、全体、味方などの対象指定
- 待機/防御: ターンスキップや被ダメージ軽減
