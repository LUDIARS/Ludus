# 目的

収集したアイテムを整理し、戦略的なリソースとして活用する。

# 設計思想

インベントリは「所有と整理のジレンマ」を生む。無制限だと価値が薄れ、厳しすぎるとストレスになる。自動ソートやジャンク処分の補助機能で、管理の楽しさと煩雑さのバランスを取る。

# 主要機能

- 所持数制限: 重量制限またはスロット数制限
- カテゴリ分類: 武器、防具、消費アイテム、素材など
- ソート/フィルタ: 種類、レア度、名前順の整理
- クイックスロット: 戦闘中に即座に使えるショートカット
- 倉庫/保管: 拠点での長期保管システム
