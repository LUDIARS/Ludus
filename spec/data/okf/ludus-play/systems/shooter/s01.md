# 目的

画面中央のクロスヘアと実際の弾道を関連付け、正確な射撃を可能にする。

# 設計思想

照準システムは「意図と結果の直結」を目指す。完全なリアリズムは必須ではなく、プレイヤーが「当たるべき場所に当たった」と感じることが重要。エイムアシストは「補助」であり「自動化」ではない線引きが鍵。

# 主要機能

- レティクル/クロスヘア: 画面中心の照準マーカー
- レイキャスト/弾道計算: 射線上のヒット判定
- エイムアシスト: コントローラー用の照準補正
- スナップエイム: ターゲットに自動的に吸い付く
- 弾道拡散(Spread): 連射時の精度低下
