# 目的

銃器発射時の反動を再現し、連射時の制御スキルを要求する。

# 設計思想

リコイルは「武器の重み」を伝える装置。完全にランダムだとプレイヤーは制御できず、完全に固定だと単調なパターン暗記になる。学習可能だが習得に練習が必要なバランスが理想。

# 主要機能

- 視点の跳ね上がり: 発射ごとにカメラが上方向に移動
- 横揺れパターン: 左右へのランダムまたは固定パターンの揺れ
- 反動リセット時間: 射撃停止後、照準が元に戻る速度
- 連射時の累積: 撃ち続けるほど反動が増大
- しゃがみ/静止時の軽減: 姿勢による反動の変化
