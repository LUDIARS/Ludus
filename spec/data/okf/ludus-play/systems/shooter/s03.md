# 目的

弾が命中したことを即座に伝え、プレイヤーの射撃を補強する。

# 設計思想

ヒットフィードバックは「成功の報酬」として機能する。視覚・聴覚・触覚(コントローラー振動)の複合的なフィードバックが、射撃の満足感を作る。過度に派手だと画面が見づらくなるため、明確さと控えめさのバランスが重要。

# 主要機能

- ヒットマーカー: クロスヘアの変化や専用アイコン表示
- ヒット音: 金属音や肉を打つ音などの聴覚フィードバック
- ダメージ数値: ヒットした箇所に数値表示
- ヘッドショットマーカー: 重要部位への命中を強調
- キルフィード: 倒した敵の通知
