# 目的

弾薬管理を通じて戦術的な判断を強制し、連続射撃に制約を設ける。

# 設計思想

リロードは「攻撃の休符」として機能する。無限の弾薬は緊張感を削ぎ、リロードが遅すぎるとストレスになる。リロードキャンセルやタクティカルリロードは、上級者向けの最適化手段。

# 主要機能

- 残弾数管理: マガジン内の弾数とリザーブ弾数
- リロード時間: 武器ごとの装填にかかる時間
- 戦術リロード: 残弾がある状態でのリロード
- 空リロード: 弾切れ時のリロード(やや遅い)
- リロードキャンセル: 武器切り替えや近接攻撃で中断
- 自動リロード: 弾切れ時の自動装填(オプション)
