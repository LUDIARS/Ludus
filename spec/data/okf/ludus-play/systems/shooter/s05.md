# 目的

プレイヤーの生存状態を管理し、ダメージと回復のメカニクスを提供する。

# 設計思想

ヘルスシステムは「生存のゲーム化」である。従来の回復アイテム方式は探索を強制し、自動回復方式はテンポを重視する。シールドは「短期的な耐久力」と「長期的な体力」を分離し、戦術の幅を広げる。

# 主要機能

- ヘルスゲージ: 現在の体力表示
- 自動回復: 一定時間ダメージを受けないと回復開始
- シールド: ヘルスの前段階の防御層
- ダメージ方向表示: どこから撃たれたかを画面端で示す
- 画面効果: 低体力時の赤み、血しぶきエフェクト
- 即死判定: 一定以上のダメージで即座に倒れる
