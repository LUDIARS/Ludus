# 目的

銃弾の物理的挙動を再現し、距離や環境による影響を表現する。

# 設計思想

弾道システムは「リアリズムとゲーム性のバランス」を問う。ヒットスキャンは即応性が高いが単調、発射体は面白いが難易度が上がる。ゲームのペースに応じて選択する。

# 主要機能

- ヒットスキャン: 即座に着弾する瞬間判定
- 発射体(Projectile): 物理的に飛ぶ弾丸オブジェクト
- 弾道落下: 重力による弾道の下降
- 貫通判定: 壁や敵を貫く弾丸
- リコシェット(跳弾): 壁面での反射
