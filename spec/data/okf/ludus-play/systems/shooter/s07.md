# 目的

直接射線が通らない場所への攻撃や、エリア制圧を可能にする。

# 設計思想

グレネードは「間接攻撃の代表」として機能する。軌道予測の表示は初心者への配慮だが、完全表示は戦術性を損なう。物理的なバウンスは予測を難しくし、スキルの差を生む。

# 主要機能

- 投擲軌道表示: 着地点の予測線またはアーク
- タイマー/着弾起爆: 時間経過または接触で爆発
- バウンス判定: 壁や床で跳ね返る挙動
- クック(調理): 投げる前にタイマーを進める
- 種類の多様性: フラグ、スモーク、スタングレネードなど
