# 目的

精密射撃モードを提供し、移動速度と引き換えに命中精度を向上させる。

# 設計思想

ADSは「精密性と視野のトレードオフ」を体現する。常にADSが有利だと戦闘が単調になるため、近距離では腰撃ちが有効なバランスが重要。ズーム倍率とFOV(視野角)の調整がゲームペースを決める。

# 主要機能

- 腰撃ち(Hip Fire): 通常状態の低精度射撃
- ADS/照準: スコープを覗き込み精度向上
- ズーム倍率: 視野が狭まり遠距離が見やすくなる
- 移動速度低下: ADS中は歩行速度が減少
- 揺れ/スウェイ: スコープ内の微細な揺れ
- 息止め: 一時的に揺れを抑える
