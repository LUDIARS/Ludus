# 目的

ゴールド、木材、食料などの資源を収集・配分し、経済の循環を作る。

# 設計思想

リソース管理は「経済のゲーム化」である。単一リソースは単純だが浅く、多すぎると複雑になる。3-5種類が戦略性と理解しやすさのバランス。資源の相互依存(木材で建物→建物で食料生産)がゲームループを作る。

# 主要機能

- リソースタイプ: 複数種類の資源(ゴールド、木材、石、食料など)
- 収集メカニクス: 労働者配置、自動生成、建物生産
- 消費と生産: ユニット作成、建物建設でのコスト
- 収支バランス: 収入と支出の可視化
- 上限管理: ストレージ容量と余剰資源
