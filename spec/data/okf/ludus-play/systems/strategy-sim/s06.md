# 目的

地形の高低差や障害物を戦術要素として組み込み、位置取りの重要性を高める。

# 設計思想

地形システムは「戦場の多様性」を作る。平坦なマップは単調で、複雑すぎると理解困難。視覚的に明確な高低差表現と、数値での効果提示が理解を助ける。地形とユニット特性の相互作用(騎兵は平地で速いが森では遅いなど)が深みを生む。

# 主要機能

- 地形タイプ: 平地、森、山、水域など
- 移動コスト: 地形ごとの移動速度変化
- 防御ボーナス: 森や城壁での防御力上昇
- 高低差: 高所からの攻撃ボーナス
- 遮蔽物: 視界と射線を遮る障害
