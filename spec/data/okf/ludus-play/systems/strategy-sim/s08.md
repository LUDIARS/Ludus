# 目的

複数の勝利ルートを提供し、多様な戦略とプレイスタイルを可能にする。

# 設計思想

勝利条件は「ゲームの終わり方の多様化」である。単一条件だとプレイスタイルが固定化し、多すぎると焦点がぼやける。各条件が互いに干渉する(軍事に資源を使うと科学が遅れるなど)設計が、戦略的選択を生む。

# 主要機能

- 征服勝利: すべての敵を倒す
- 科学勝利: 特定の技術を完成させる
- 文化勝利: 文化的影響力で支配
- 経済勝利: 一定の富を蓄積
- 時間制限勝利: 制限時間終了時の評価
- 進捗表示: 各勝利条件への達成度
