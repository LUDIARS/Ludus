# 目的

防衛施設を戦略的に配置し、敵の進路を制御する。

# 設計思想

配置システムは「空間の戦略化」である。自由配置は創造的だが難しく、固定グリッドは理解しやすいが制約が強い。敵の経路と射程範囲の可視化で、初心者でも効果的な配置を理解できるようにする。

# 主要機能

- 配置可能エリア: グリッドまたは自由配置
- 配置コスト: タワーごとの建設費用
- 射程範囲: 攻撃可能な円形エリア
- 配置制限: 同時設置可能な数や種類
- 配置取り消し: 売却による資金回収
- 配置タイミング: ウェーブ中/準備時間
