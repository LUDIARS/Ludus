# 目的

多様な防衛手段を提供し、敵に応じた使い分けを要求する。

# 設計思想

タワータイプは「ロックペーパーシザーズ」を作る。単一の最強タワーがあると戦略性が失われるため、敵の種類(装甲、飛行、群れ)に対して有利不利を設定する。

# 主要機能

- 基本タワー: 単体攻撃、範囲攻撃、遠距離など
- 特殊効果: スロー、毒、スタン、防御デバフ
- 対空/対地: 飛行敵専用または地上専用
- ダメージタイプ: 物理、魔法、炎、氷など
- 攻撃速度: 高速低威力 vs 低速高威力
- ターゲット優先度: 先頭、後方、体力最大/最小
