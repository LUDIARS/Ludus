# 目的

既存タワーの性能向上を提供し、新規建設との選択を生む。

# 設計思想

アップグレードは「集中と分散のジレンマ」を作る。少数の強力タワーと、多数の弱いタワーのどちらが有利かは状況次第。強化コストの累進性(1→2は安い、2→3は高い)で、バランスを調整する。

# 主要機能

- 段階的強化: レベル1→2→3→最大
- 強化コスト: レベルごとに増加する費用
- 性能向上: ダメージ、射程、速度の増加
- 分岐進化: 複数の強化ルート選択
- 特殊能力解放: 高レベルで新効果
- 最大レベル: 上限の設定
