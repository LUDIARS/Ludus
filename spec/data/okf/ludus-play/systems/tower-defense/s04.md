# 目的

段階的に難易度を上げ、準備と実戦のリズムを作る。

# 設計思想

ウェーブシステムは「緊張と弛緩のリズム」を作る。常に敵が来ると対応できず、長すぎる準備時間は退屈。ウェーブ間の短い休息で、戦略の調整と次への準備をさせる。

# 主要機能

- ウェーブ番号: 進行状況の明示
- 準備時間: 次のウェーブまでの猶予
- 敵の種類: ウェーブごとに異なる編成
- 難易度曲線: 徐々に強く、多くなる
- ボスウェーブ: 特定タイミングの強敵
- 早送り: 準備完了後の時間短縮
