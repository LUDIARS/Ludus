# 目的

敵の移動ルートを定義し、配置戦略の基盤を作る。

# 設計思想

経路システムは「予測可能性と戦略性のバランス」である。固定経路は分かりやすいが単調、完全自由は予測困難。複数経路や条件分岐(体力が多い敵は近道、少ない敵は遠回りなど)で深みを加える。

# 主要機能

- 固定経路: あらかじめ決まった道
- 複数経路: 分岐や合流がある道
- 経路選択: 敵が最短または最適ルート選択
- 経路ブロック: タワーで道を塞ぐ(一部のゲーム)
- 迂回AI: 塞がれた場合の別ルート探索
- ゴール地点: 敵の到達目標
