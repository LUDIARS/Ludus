# 目的

資金の獲得と消費を管理し、投資判断を要求する。

# 設計思想

経済システムは「時間的な資源配分」である。序盤に全資金を使うと後半が苦しく、貯め込むと序盤を乗り切れない。利息システムは貯蓄へのインセンティブだが、強すぎると防衛をおろそかにする誘惑になる。

# 主要機能

- 初期資金: ゲーム開始時の所持金
- 敵撃破報酬: 倒すごとに獲得
- ウェーブ完了ボーナス: クリア報酬
- 利息システム: 残金に応じた追加収入
- 資金タワー: 収入増加専用の建物
- 消費先: タワー建設、強化、特殊能力
