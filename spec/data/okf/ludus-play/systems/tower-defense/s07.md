# 目的

失敗条件を定義し、完璧を求めない柔軟性を提供する。

# 設計思想

ライフシステムは「完璧主義の緩和」である。1体でも通過したら即失敗だと厳しすぎて挫折を招く。複数ライフで「ギリギリで勝つ」体験を許容しつつ、パーフェクト達成への動機も残す。

# 主要機能

- ライフポイント: 敵の通過許容回数
- ダメージ量: 敵の強さに応じた減少
- ライフ回復: 特定条件での回復(稀)
- ゲームオーバー: ライフ0で敗北
- 星評価: ライフ残量で評価
- パーフェクト報酬: ノーダメージボーナス
