# 目的

タワー以外の介入手段を提供し、緊急時の対応を可能にする。

# 設計思想

特殊能力は「プレイヤーの直接介入」を可能にする。タワーのみだと配置後は見守るだけになり、能動性が低い。限られた回数の強力スキルで、「ここぞ」という時の選択を迫る。

# 主要機能

- アクティブスキル: プレイヤーが手動発動
- クールダウン: 再使用までの待機時間
- 能力の種類: 爆撃、時間停止、回復、強化など
- スキルコスト: 資金またはゲージ消費
- 範囲指定: 効果範囲の選択
- 緊急対応: 漏れそうな時の保険
