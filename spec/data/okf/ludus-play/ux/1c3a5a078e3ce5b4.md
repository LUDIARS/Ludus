# 原文由来の効果

- 継続性: 参加しやすい試合導線
- 継続性: 大きな冒険を中断できる
- 継続性: 寄り道後も目的に戻れる
- 継続性: 待ち時間を選べる
- 継続性: 推理の蓄積を失わない
- 継続性: 物語の位置を失わない
- 継続性: 長い対局を生活に合わせられる
