# FBXモデル処理モジュール定義

## 概要
FBXバイナリファイルを解析し、頂点・インデックス・法線・UV座標・マテリアル情報を抽出して描画可能なメッシュデータを構築する

## カテゴリ
システム

## 所属ドメイン
モデル

## 必要なデータ
- FBXバイナリファイルのバイト列

## 変数
- ファイルバイト列
- FBXバージョン
- 頂点配列(x, y, z)
- インデックス配列
- 法線配列(nx, ny, nz)
- UV座標配列(u, v)
- マテリアル配列(名前, ディフューズ色RGBA, テクスチャパス)
- メッシュ配列(名前, 頂点インデックス範囲, マテリアルインデックス)
- パース状態(未読/読込中/完了/エラー)
- エラー内容

## 依存
- なし

## 作業
### 入力
- FBXバイナリファイルのバイト列

### 出力
- メッシュデータ(頂点配列, インデックス配列, 法線配列, UV座標配列, マテリアル配列, メッシュ配列)

### タスク
- 先頭20バイトからFBXヘッダマジック「Kaydara FBX Binary」を検証し、不一致ならエラー状態にする
- ヘッダ直後の4バイトからFBXバージョン番号をリトルエンディアンで読み取る
- ノードレコードを再帰的に解析し、EndOffset・プロパティ数・プロパティリスト長・名前を読み取る
- Objectsノード配下のGeometryノードからVertices配列をdouble型で読み取り頂点配列に格納する
- GeometryノードからPolygonVertexIndexを読み取り、負値ビット反転でポリゴン終端を判定しインデックス配列に変換する
- GeometryノードのLayerElementNormalからNormals配列を読み取り法線配列に格納する
- GeometryノードのLayerElementUVからUV配列を読み取りUV座標配列に格納する
- Objectsノード配下のMaterialノードからマテリアル名とディフューズ色を読み取りマテリアル配列に格納する
- ConnectionsノードからGeometryとMaterialの親子関係を解析しメッシュにマテリアルインデックスを割り当てる
- 4角ポリゴンを2つの3角ポリゴンに分割しインデックス配列を三角形単位に正規化する
- パース状態を完了にし、メッシュデータを出力する


# テスト
- 正規のFBXバイナリヘッダを持つファイルを読み込みパース状態が完了になること
- 先頭が「Kaydara FBX Binary」でないバイト列を渡した場合パース状態がエラーになりエラー内容にヘッダ不正を示す文言が含まれること
- 三角形1枚(頂点3個)のFBXを読み込み頂点配列の要素数が3かつインデックス配列が[0,1,2]であること
- 四角形1枚(頂点4個)のFBXを読み込みインデックス配列の要素数が6(三角形2枚分)であること
- 法線情報を持つFBXを読み込み法線配列の要素数が頂点配列の要素数と一致すること
- UV座標を持つFBXを読み込みUV座標配列の各要素が0.0以上1.0以下の範囲であること
- マテリアルを1つ持つFBXを読み込みマテリアル配列の要素数が1かつディフューズ色がRGBA値を持つこと
- 空のバイト列(0バイト)を渡した場合パース状態がエラーになること
