# 線描画モジュール定義

## 概要
2点間をBresenhamアルゴリズムで補間し線分を描画する

## カテゴリ
ゲームオブジェクト

## 所属ドメイン
描画

## 必要なデータ
- 描画先サーフェスの幅と高さ

## 変数
- 描画色(RGBA)
- 始点(x, y)
- 終点(x, y)
- 線の太さ
- 描画バッファ

## 依存
- なし

## 作業
### 入力
- 始点(x, y)
- 終点(x, y)
- 描画色(RGBA)
- 線の太さ

### 出力
- 描画済みバッファ

### タスク
- 始点から終点までBresenhamアルゴリズムでピクセル座標を算出する
- 各ピクセル座標に対し線の太さ分の垂直方向ピクセルを描画色で書き込む
- 範囲外のピクセルはクリッピングして無視する


# テスト
- (0,0)から(100,50)へ線を描画し、始点・終点・中間点のピクセルが描画色であること
- (50,0)から(50,100)へ垂直線を描画し、(50,50)のピクセルが描画色であること
- (0,0)から(0,0)へ同一点の線を描画し、1ピクセルのみ描画されること
- 線の太さを3に設定して(0,50)から(100,50)へ水平線を描画し、y=49,50,51の3行にピクセルがあること
- サーフェス範囲外にはみ出す線を描画してもエラーが発生しないこと
