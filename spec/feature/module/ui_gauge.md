# UIゲージモジュール定義

## 概要
現在値と最大値の比率に応じた塗りつぶし領域を持つゲージバーを描画バッファへ描画する

## カテゴリ
UI

## 所属ドメイン
UI

## 必要なデータ
- 描画先サーフェスの幅と高さ

## 変数
- 描画バッファ
- 位置x
- 位置y
- 幅
- 高さ
- 背景色RGBA
- 前景色RGBA
- 枠線色RGBA
- 枠線太さ
- 現在値
- 最大値
- 方向（左, 右, 上, 下）
- 表示フラグ

## 依存
- 矩形描画モジュール

## 作業
### 入力
- ゲージの属性（位置x, 位置y, 幅, 高さ, 背景色RGBA, 前景色RGBA, 枠線色RGBA, 枠線太さ, 現在値, 最大値, 方向, 表示フラグ）
- 描画バッファ

### 出力
- 描画済みバッファ

### タスク
- 表示フラグがfalseの場合、描画処理をスキップして描画バッファをそのまま返す
- 枠線太さが1以上の場合、枠線色で枠線矩形を描画する
- 枠線の内側領域を背景色で塗りつぶし矩形を描画する
- 現在値÷最大値の比率を算出する（現在値が最大値を超える場合は1.0に丸める、0未満の場合は0.0に丸める）
- 比率に応じた領域を方向に沿って前景色で塗りつぶし矩形を描画する（右なら左端から右へ、左なら右端から左へ、下なら上端から下へ、上なら下端から上へ）
- サーフェス範囲外のピクセルはクリッピングして無視する


# テスト
- ゲージ(x=10, y=10, 幅=100, 高さ=20, 現在値=50, 最大値=100, 方向=右)を描画し、(35,20)が前景色かつ(85,20)が背景色であること
- 現在値=0のゲージを描画し、枠線内側が全て背景色であること
- 現在値=最大値のゲージを描画し、枠線内側が全て前景色であること
- 現在値が最大値を超える場合、枠線内側が全て前景色であること（比率が1.0に丸められること）
- 方向=左のゲージ(現在値=50, 最大値=100)を描画し、右半分が前景色かつ左半分が背景色であること
- 表示フラグがfalseの場合、描画バッファが変化しないこと
- サーフェス範囲外にはみ出すゲージを描画してもエラーが発生しないこと
