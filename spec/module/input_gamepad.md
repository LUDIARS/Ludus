# ゲームパッド入力モジュール定義

## 概要
ゲームパッドのボタン状態・アナログスティック・トリガー値をフレームごとに管理し問い合わせに応答する

## カテゴリ
システム

## 所属ドメイン
入力

## 必要なデータ
- デッドゾーン閾値（スティック入力の無効範囲）

## 変数
- 現フレームのボタン押下状態配列
- 前フレームのボタン押下状態配列
- 左スティック軸値(x, y)（-1.0〜1.0）
- 右スティック軸値(x, y)（-1.0〜1.0）
- 左トリガー値（0.0〜1.0）
- 右トリガー値（0.0〜1.0）
- 接続状態

## 依存
- なし

## 作業
### 入力
- OSから取得したゲームパッドイベント（ボタン押下・離上、スティック軸変化、トリガー値変化、接続・切断）

### 出力
- なし

### タスク
- フレーム開始時に現フレームのボタン押下状態配列を前フレームのボタン押下状態配列へコピーする
- OSから受け取ったボタンイベントを現フレームのボタン押下状態配列に反映する（押下ならtrue、離上ならfalse）
- OSから受け取ったスティック軸変化イベントを該当スティックの軸値に反映し、デッドゾーン閾値未満の入力は0に補正する
- OSから受け取ったトリガー値変化イベントを該当トリガー値に反映し、0.0〜1.0の範囲にクランプする
- OSから受け取った接続・切断イベントを接続状態に反映する
- ゲームパッドが接続中かを返す
- 指定ボタンが現フレームで押下状態かを返す
- 指定ボタンが現フレームで新たに押されたかを返す（現フレームがtrueかつ前フレームがfalse）
- 指定ボタンが現フレームで離されたかを返す（現フレームがfalseかつ前フレームがtrue）
- 指定スティックの軸値を返す
- 指定トリガーの値を返す


# テスト
- Aボタンを押下した状態で押下判定を問い合わせ、trueが返ること
- Aボタンを今フレームで初めて押した状態で新規押下判定を問い合わせ、trueが返ること
- Aボタンを2フレーム連続で押下した状態で新規押下判定を問い合わせ、falseが返ること
- Bボタンを前フレームまで押下し今フレームで離した状態で離上判定を問い合わせ、trueが返ること
- 左スティックをx=0.8, y=-0.5に傾けた状態で軸値を問い合わせ、(0.8, -0.5)が返ること
- 左スティックをデッドゾーン閾値0.2に対しx=0.1の入力で軸値を問い合わせ、0が返ること
- 右トリガーを0.7まで引いた状態でトリガー値を問い合わせ、0.7が返ること
- ゲームパッド未接続の状態で接続判定を問い合わせ、falseが返ること
- ゲームパッドを接続した状態で接続判定を問い合わせ、trueが返ること
