# キーボード入力モジュール定義

## 概要
キーボードのキー状態（押下・離上・保持）をフレームごとに管理し問い合わせに応答する

## カテゴリ
システム

## 所属ドメイン
入力

## 必要なデータ
- キーコード一覧（対応するキーの識別子）

## 変数
- 現フレームのキー押下状態配列
- 前フレームのキー押下状態配列

## 依存
- なし

## 作業
### 入力
- OSから取得したキーイベント（キーコード、押下または離上）

### 出力
- なし

### タスク
- フレーム開始時に現フレームのキー押下状態配列を前フレームのキー押下状態配列へコピーする
- OSから受け取ったキーイベントを現フレームのキー押下状態配列に反映する（押下ならtrue、離上ならfalse）
- 指定キーコードが現フレームで押下状態かを返す（現フレーム配列がtrue）
- 指定キーコードが現フレームで新たに押されたかを返す（現フレームがtrueかつ前フレームがfalse）
- 指定キーコードが現フレームで離されたかを返す（現フレームがfalseかつ前フレームがtrue）


# テスト
- Aキーを押下した状態で押下判定を問い合わせ、trueが返ること
- Aキーを押下していない状態で押下判定を問い合わせ、falseが返ること
- Aキーを今フレームで初めて押した状態で新規押下判定を問い合わせ、trueが返ること
- Aキーを2フレーム連続で押下した状態で新規押下判定を問い合わせ、falseが返ること
- Aキーを前フレームまで押下し今フレームで離した状態で離上判定を問い合わせ、trueが返ること
- 複数キー（A, B）を同時に押下した状態で各キーの押下判定を問い合わせ、いずれもtrueが返ること
- フレーム更新を実行し、前フレーム状態が正しく現フレーム状態のコピーに置き換わること
