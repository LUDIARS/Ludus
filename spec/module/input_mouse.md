# マウス入力モジュール定義

## 概要
マウスのカーソル座標・ボタン状態・ホイール量をフレームごとに管理し問い合わせに応答する

## カテゴリ
システム

## 所属ドメイン
入力

## 必要なデータ
- 画面の幅と高さ（座標クランプ用）

## 変数
- カーソル座標(x, y)
- 前フレームのカーソル座標(x, y)
- 現フレームのボタン押下状態配列（左・中・右）
- 前フレームのボタン押下状態配列（左・中・右）
- フレーム内ホイールスクロール量

## 依存
- なし

## 作業
### 入力
- OSから取得したマウスイベント（カーソル移動、ボタン押下・離上、ホイールスクロール）

### 出力
- なし

### タスク
- フレーム開始時に現フレームのボタン押下状態配列を前フレームのボタン押下状態配列へコピーする
- フレーム開始時にカーソル座標を前フレームのカーソル座標へコピーし、ホイールスクロール量を0にリセットする
- OSから受け取ったカーソル移動イベントをカーソル座標に反映し、画面範囲内にクランプする
- OSから受け取ったボタンイベントを現フレームのボタン押下状態配列に反映する（押下ならtrue、離上ならfalse）
- OSから受け取ったホイールイベントをフレーム内ホイールスクロール量に加算する
- 現在のカーソル座標を返す
- 前フレームからのカーソル移動量（現座標 − 前座標）を返す
- 指定ボタンが現フレームで押下状態かを返す
- 指定ボタンが現フレームで新たに押されたかを返す（現フレームがtrueかつ前フレームがfalse）
- 指定ボタンが現フレームで離されたかを返す（現フレームがfalseかつ前フレームがtrue）
- フレーム内ホイールスクロール量を返す


# テスト
- カーソルを(100, 200)に移動した状態で座標を問い合わせ、(100, 200)が返ること
- カーソルを画面外座標(-10, 500)に移動した場合、画面範囲内にクランプされた値が返ること
- 前フレーム(50, 50)から現フレーム(80, 60)へ移動した状態で移動量を問い合わせ、(30, 10)が返ること
- 左ボタンを押下した状態で押下判定を問い合わせ、trueが返ること
- 左ボタンを今フレームで初めて押した状態で新規押下判定を問い合わせ、trueが返ること
- 左ボタンを2フレーム連続で押下した状態で新規押下判定を問い合わせ、falseが返ること
- 右ボタンを前フレームまで押下し今フレームで離した状態で離上判定を問い合わせ、trueが返ること
- ホイールを上方向に3回スクロールした状態でスクロール量を問い合わせ、3が返ること
- フレーム更新後にホイールスクロール量が0にリセットされていること
