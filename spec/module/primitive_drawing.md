# プリミティブ描画モジュール定義

## カテゴリ
UI

## 所属ドメイン
描画

## 必要なデータ
- 描画先サーフェスの幅と高さ
- 描画色(RGBA)
- 線の太さ

## 変数
- 現在の描画色
- 現在の線の太さ
- 描画バッファ

## 依存
- なし

## 作業
### 入力
- プリミティブ種別(点/線/矩形/円/三角形)
- 座標(x, y)
- サイズパラメータ(幅/高さ/半径)
- 塗りつぶしフラグ

### 出力
- 描画済みバッファ

### タスク
- 点の描画
- 線分の描画(2点間)
- 矩形の描画(塗りつぶし/枠線)
- 円の描画(塗りつぶし/枠線)
- 三角形の描画(3頂点指定、塗りつぶし/枠線)
- 描画色の変更
- 線の太さの変更
- バッファのクリア


# テスト
- 指定座標に点が描画されること
- 2点間に線分が描画されること
- 指定位置・サイズで矩形が描画されること
- 矩形の塗りつぶしと枠線が切り替わること
- 指定位置・半径で円が描画されること
- 円の塗りつぶしと枠線が切り替わること
- 3頂点を指定して三角形が描画されること
- 描画色の変更が後続の描画に反映されること
- 線の太さの変更が後続の描画に反映されること
- バッファクリアで描画内容が消去されること
- サーフェス範囲外への描画がエラーにならないこと
