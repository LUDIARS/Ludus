# 点描画モジュール定義

## 概要
指定座標のピクセルに描画色を書き込む

## カテゴリ
ゲームオブジェクト

## 所属ドメイン
描画

## 必要なデータ
- 描画先サーフェスの幅と高さ

## 変数
- 描画色(RGBA)
- 座標(x, y)
- 描画バッファ

## 依存
- なし

## 作業
### 入力
- 座標(x, y)
- 描画色(RGBA)

### 出力
- 描画済みバッファ

### タスク
- 指定座標(x, y)が描画バッファの範囲内か判定し、範囲内なら該当ピクセルに描画色を書き込む
- 範囲外の座標は無視して何もしない


# テスト
- 座標(10, 20)に赤色(255,0,0,255)で点を描画し、バッファの該当ピクセルが赤色であること
- 座標(0, 0)に描画し、バッファ左上のピクセルが描画色であること
- サーフェス範囲外の座標(-1, -1)に点を描画してもエラーが発生しないこと
- 描画色を青(0,0,255,255)に変更して描画し、ピクセルが青色であること
