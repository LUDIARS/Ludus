# UIボタンモジュール定義

## 概要
通常・押下・無効の3状態を持つボタンを描画バッファへ描画する

## カテゴリ
UI

## 所属ドメイン
UI

## 必要なデータ
- 描画先サーフェスの幅と高さ

## 変数
- 描画バッファ
- 位置x
- 位置y
- 幅
- 高さ
- 通常時背景色RGBA
- 押下時背景色RGBA
- 無効時背景色RGBA
- 枠線色RGBA
- 枠線太さ
- 状態（通常, 押下, 無効）
- 表示フラグ

## 依存
- 矩形描画モジュール

## 作業
### 入力
- ボタンの属性（位置x, 位置y, 幅, 高さ, 通常時背景色RGBA, 押下時背景色RGBA, 無効時背景色RGBA, 枠線色RGBA, 枠線太さ, 状態, 表示フラグ）
- 描画バッファ

### 出力
- 描画済みバッファ

### タスク
- 表示フラグがfalseの場合、描画処理をスキップして描画バッファをそのまま返す
- 状態が通常の場合は通常時背景色、押下の場合は押下時背景色、無効の場合は無効時背景色を描画色として選択する
- 選択した描画色で塗りつぶし矩形を描画する
- 枠線太さが1以上の場合、枠線色で枠線矩形を描画する
- サーフェス範囲外のピクセルはクリッピングして無視する


# テスト
- ボタン(x=20, y=20, 幅=80, 高さ=30, 状態=通常)を描画し、内部(60,35)が通常時背景色であること
- ボタンの状態を押下に変更して描画し、内部(60,35)が押下時背景色に変わること
- ボタンの状態を無効に変更して描画し、内部(60,35)が無効時背景色に変わること
- 枠線太さ=2のボタンを描画し、(20,20)と(21,21)が枠線色であること
- 表示フラグがfalseの場合、描画バッファが変化しないこと
- サーフェス範囲外にはみ出すボタンを描画してもエラーが発生しないこと
