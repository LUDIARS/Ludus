# UIラベルモジュール定義

## 概要
フォントグリフデータを用いてテキスト文字列を描画バッファへ描画する

## カテゴリ
UI

## 所属ドメイン
UI

## 必要なデータ
- 描画先サーフェスの幅と高さ

## 変数
- 描画バッファ
- 位置x
- 位置y
- 文字列
- 文字色RGBA
- フォントID
- 表示フラグ

## 依存
- 点描画モジュール

## 作業
### 入力
- ラベルの属性（位置x, 位置y, 文字列, 文字色RGBA, フォントID, 表示フラグ）
- 描画バッファ

### 出力
- 描画済みバッファ

### タスク
- 表示フラグがfalseの場合、描画処理をスキップして描画バッファをそのまま返す
- フォントIDに対応するグリフデータを取得する
- 文字列の各文字について、対応するグリフのビットマップを取得する
- グリフビットマップの各ピクセルが有効な箇所を文字色で描画バッファへ転写する
- 文字ごとにグリフ幅分だけ描画位置xを進める
- サーフェス範囲外のピクセルはクリッピングして無視する


# テスト
- ラベル(x=10, y=10, 文字列="A", 文字色=白, フォントID=0)を描画し、グリフデータの有効ピクセル位置に文字色が書き込まれること
- 文字列が空の場合、描画バッファが変化しないこと
- 表示フラグがfalseの場合、描画バッファが変化しないこと
- 複数文字の文字列を描画し、各文字がグリフ幅分ずつ右にずれて配置されること
- サーフェス範囲外にはみ出すラベルを描画してもエラーが発生しないこと
