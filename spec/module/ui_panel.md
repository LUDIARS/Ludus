# UIパネルモジュール定義

## 概要
矩形の背景領域と枠線を持つパネルを描画バッファへ描画する

## カテゴリ
UI

## 所属ドメイン
UI

## 必要なデータ
- 描画先サーフェスの幅と高さ

## 変数
- 描画バッファ
- 位置x
- 位置y
- 幅
- 高さ
- 背景色RGBA
- 枠線色RGBA
- 枠線太さ
- 表示フラグ

## 依存
- 矩形描画モジュール

## 作業
### 入力
- パネルの属性（位置x, 位置y, 幅, 高さ, 背景色RGBA, 枠線色RGBA, 枠線太さ, 表示フラグ）
- 描画バッファ

### 出力
- 描画済みバッファ

### タスク
- 表示フラグがfalseの場合、描画処理をスキップして描画バッファをそのまま返す
- 枠線太さが1以上の場合、枠線色で枠線矩形を描画する
- 枠線の内側領域を背景色で塗りつぶし矩形を描画する
- サーフェス範囲外のピクセルはクリッピングして無視する


# テスト
- パネル(x=10, y=10, 幅=100, 高さ=50, 背景色=白, 枠線色=黒, 枠線太さ=1)を描画し、(10,10)が枠線色かつ(50,35)が背景色であること
- 枠線太さ=0のパネル(x=10, y=10, 幅=100, 高さ=50, 背景色=青)を描画し、(10,10)が背景色であること
- 表示フラグがfalseの場合、描画バッファが変化しないこと
- サーフェス範囲外にはみ出すパネルを描画してもエラーが発生しないこと
