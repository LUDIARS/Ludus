# UI描画モジュール定義

## 概要
UI要素リストを受け取り、各要素の種別に応じた描画処理を実行して描画バッファへ出力する

## カテゴリ
UI

## 所属ドメイン
描画

## 必要なデータ
- 描画先サーフェスの幅と高さ

## 変数
- UI要素リスト
- 描画バッファ
- UI要素の共通属性（位置x, 位置y, 幅, 高さ, 表示フラグ, Zオーダー）
- パネル属性（背景色RGBA, 枠線色RGBA, 枠線太さ）
- ボタン属性（通常時背景色RGBA, 押下時背景色RGBA, 無効時背景色RGBA, 枠線色RGBA, 枠線太さ, 状態）
- ラベル属性（文字色RGBA, フォントID, 文字列）
- ゲージ属性（背景色RGBA, 前景色RGBA, 枠線色RGBA, 枠線太さ, 現在値, 最大値, 方向）

## 依存
- 矩形描画モジュール

## 作業
### 入力
- UI要素リスト

### 出力
- 描画済みバッファ

### タスク
- UI要素リストをZオーダーの昇順にソートする
- ソート済みリストを先頭から順に走査し、表示フラグがfalseの要素をスキップする
- 要素種別がパネルの場合、枠線太さが1以上なら枠線色で枠線矩形を描画し、内部を背景色で塗りつぶし矩形を描画する
- 要素種別がボタンの場合、状態に対応する背景色で塗りつぶし矩形を描画し、枠線太さが1以上なら枠線色で枠線矩形を描画する
- 要素種別がラベルの場合、フォントIDに対応するグリフデータを取得し、文字列の各文字を文字色で1ピクセルずつ描画バッファへ転写する
- 要素種別がゲージの場合、枠線色で枠線矩形を描画し、背景色で内部を塗りつぶし、現在値÷最大値の比率に応じた領域を前景色で方向に沿って塗りつぶし矩形を描画する
- サーフェス範囲外のピクセルはクリッピングして無視する


# テスト
- パネル要素(x=10, y=10, 幅=100, 高さ=50, 背景色=白, 枠線色=黒, 枠線太さ=1)を描画し、(10,10)が枠線色かつ(50,35)が背景色であること
- ボタン要素(x=20, y=20, 幅=80, 高さ=30, 状態=通常)を描画し、内部(60,35)が通常時背景色であること
- ボタン要素の状態を押下に変更して描画し、内部(60,35)が押下時背景色に変わること
- ゲージ要素(x=10, y=10, 幅=100, 高さ=20, 現在値=50, 最大値=100, 方向=右)を描画し、(35,20)が前景色かつ(85,20)が背景色であること
- ゲージ要素の現在値を0にして描画し、内部全体が背景色であること
- 表示フラグがfalseのUI要素が描画バッファに反映されないこと
- Zオーダーが大きい要素が小さい要素の上に描画されること（同座標に重なるパネル2枚でZオーダー大の色が最終バッファに残ること）
- UI要素リストが空の場合、描画バッファが初期状態のままであること
- サーフェス範囲外にはみ出すUI要素を描画してもエラーが発生しないこと
